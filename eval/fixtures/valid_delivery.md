- 剧情/故事变化：周诚即将签字，林岚选择出声但没有夺走文件，观众确认阻止方式。
- 人物与连续性：林岚/ASSET-001在画左中景面向右；周诚/ASSET-002在画右前景面向左；ASSET-003位于两人之间。
- 演员调度/动作节拍：周诚笔尖下落 -> 林岚停住伸手趋势并开口 -> 周诚笔尖悬停 -> 林岚手掌离开桌沿。
- 情绪与表演：林岚起始急切 -> 看见笔尖将落 -> 吸气后压低音量、语速平稳 -> 视线停在签字页而手不前伸 -> 说完等待周诚选择。

- 叙事视点/知识边界：模式=客观 | 主人=无 | 人物在场=是 | 观众当前可知=林岚发现风险但尚不知具体页码 | 进入触发=上一场落幅 | 退出触发=D-001前半句。

- 连续性/资产：SCN-001；ASSET-001、ASSET-002、ASSET-003；笔尖未落墨，林岚手已离开桌沿，交给CUT-002。

### CUT-002 | S01-B01
- 场景：SCN-001；同一会议室、内、上午，从周诚位置看向合同附件。
- 剧情/故事变化：周诚接住林岚的提醒并主动寻找异常，关系推进依赖他的选择而非她的代办。
- 人物与连续性：周诚/ASSET-002本人在场但只见右手和袖口；林岚/ASSET-001位于画外；ASSET-003保持原方向。
- 演员调度/动作节拍：周诚视线落向附件 -> 右手将纸页翻回 -> 指腹停在编号旁 -> 笔仍握在另一只手中但不签。
- 情绪与表演：周诚起始戒备 -> 听完提醒 -> 呼吸放慢、没有立即答话 -> 目光逐行搜索并用指腹定位 -> 找到异常后抬头。
- 台词/字幕：
  - D-001[2/2] | 剧情对白 | 林岚 | 画外 | 口型=无 | 文本=你先别签。
- 叙事视点/知识边界：模式=字面POV | 主人=周诚 | 人物在场=是 | 观众当前可知=周诚只知道附件可能有误 | 进入触发=D-001 | 退出触发=周诚抬头动作。
- 摄影：主观近景；65mm；机位位于周诚眼位并向下俯看桌面；附件编号居中；固定机位配合一次短焦点转移；焦点从页边到编号。
- 视觉焦点/动势：页边 -> 翻页手指 -> 编号；手向左翻页后停住，相机保持稳定。
- 声音：D-001后半句画外延续、纸张摩擦、空调底噪。

- 导演意图：字面POV只在周诚收到提醒并主动查看后进入，不提前替他知道答案。
- AI画面事实：从周诚眼位俯看同一份合同，右手翻回附件并停在编号旁；林岚不入画；纸张方向与CUT-001一致。
- 连续性/资产：SCN-001；ASSET-002右袖、ASSET-003；笔仍未落墨，编号已被找到，交给CUT-003。

- 连续性/资产：SCN-001；ASSET-001、ASSET-002、ASSET-003；签字未发生，笔横放，林岚退开，场景结束。
