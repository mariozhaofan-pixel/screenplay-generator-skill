# 从参考作品到原创剧本

用户提供参考视频、链接、片名或公开剧本，希望分析或借鉴类型、人物、剧情节奏、反转与对白时使用。本模块是 Skill 的研究和创作编排，不冒充 Coffee Break 原书章节。不默认加载完整反推分镜流程，不把资料研究当成已经观看影片。

## 先确定作品与实际材料

继承用户已定题材、时长、人物、保留项和交付范围。只有分析请求就完成分析；“照这种感觉写一集”“参考后直接成稿”等已授权创作，直接推进最多2集，不增加审批。只想讨论功能或方案时不试写整集。改现有稿时仅研究受影响部分。

先确认片名/原名、年份、创作者、版本、集数或时间区间；网页标题和文件名只是线索。同名或翻拍版本会改变结论且无法消歧时，简问一个辨识问题，其余独立资料可先找。不把预告、片段、解说、混剪、字幕合集当成完整原片。

| 输入与实际获得的材料 | 可以完成 | 必须保留的边界 |
|---|---|---|
| 本地视频或可访问的视频链接 | 按实际可审阅范围做叙事、声画和节奏分析 | 先核验媒体及覆盖范围；读取页面、下载或解码成功均不等于看过或听过 |
| 只有片名/链接，能找到公开剧本 | 分析该剧本版本的行动、人物、对白和文字结构 | 草稿、拍摄稿、誊录稿分别记，不当作上映版；页码不能直接换算成片时码 |
| 只有字幕/转录 | 分析可见文本与有依据的台词时间区间 | 不据此断言表演语气、背景声音、无对白行动、剪辑点或完整剧情 |
| 只有简介、访谈、评论 | 核对类型前提，形成有来源的结构假设与可迁移方向 | 简介不补全整片；评论只证明评论者的判断，访谈中的意图不等于已实现效果 |

对每条实际使用的结论标明“直接观察、来源记述、分析推断、原创设计”之一，并保留材料类型、版本及覆盖范围。材料之间有冲突先核版本；研究上映成片以实际成片观察为准，研究某版剧本以该文本为准，不把不同版本拼成一个虚构原片。

## 公开资料调研

按具体缺口检索，不以熟悉作品为由跳过用户明确要求的调查。优先寻找制作方/发行方的作品页和 FYC 剧本、创作者发布、正式剧本出版与公开节选、电影节场刊、主创原始访谈；再用可靠行业媒体和资料馆补足。影评、百科和社区用于发现线索或观众反应，不伪装成原剧本或作者意图。中文片名未命中时查原名、编剧名及版本。

可用查询组合：`片名 年份 编剧 剧本/文学剧本`、`原名 screenplay/script/FYC PDF`、`片名 编剧访谈/导演阐述/场刊`、`原名 draft shooting script interview`。搜索摘要只是线索：打开实际页面/文档，核题名、署名、版本日期及相关内容，再支撑结论。不强求每部电影都有公开完整剧本。

公开入口核验示例（2026-09-29；每个项目仍需重查具体页面）：[A24 官方公开的《Sing Sing》剧本](https://a24awards.com/assets/Sing-Sing-screenplay.pdf)可作为文本研究来源；[Focus Features《Land》编剧访谈](https://www.focusfeatures.com/article/interview_jesse-chatham_erin-dignam)可用于了解主创所述的开发思路。这些是查源示例，不是随包附带的全文，也不是所有影片均可取得的保证。

遇到登录、地区、链接失效、付费或抓取限制，先寻找官方替代入口、公开节选、访谈或用户已给材料；不绕过访问控制、不自动购买或注册。仍缺的部分降低结论范围，继续能做的研究和原创开发。只有缺失内容决定用户明确要求的精确分析时，才请求本地视频/文本或版本信息。用户明确不联网时沿用给定材料并说明实际缺口。

研究账本按作品建一次，不逐集重搜：`来源ID｜作品及版本｜材料类型｜直达链接/本地路径｜发布日期（已知才填）与核验日｜实际阅读/视听覆盖｜支持的结论及页/场/时码｜判断类别｜未决冲突`。同源转载不计独立证据。公开可读不等于公版或允许全文转载；只保存所需简练分析、定位和必要短引文，完整原剧本不塞入 Skill 安装包。

## 视频分析如何实际执行

先检查当前环境是否具有视频审阅、音频审阅和媒体解码能力。工具可用时核验时长、帧率、音轨、字幕和版本，使用用户指定音轨；未指定时以原声/主要音轨为主并记清，不默认听完所有译制轨。依实际工具将长视频划为连续可复核区间，保留覆盖记录和未审阅缺口；需要时用时间戳字幕/ASR辅助定位，再回看回听关键冲突、反应与揭示。不能把 ASR 当成听音，把关键帧或稀疏截图当成完整观看。

只有连续覆盖的实际审阅才支持该范围的全段叙事判断；局部观看写成片段分析。字幕校准、关键帧、场景切分和音量检测是辅助，机器检测点不是戏剧节拍。画面可看而音频不可听时，明确只分析视觉与已取得的文本，不判断声线、停顿效果或音乐意图。未提供音视频或当前工具不能真实审阅时，转为文本研究，不承诺任意链接都能自动拉片。

“第几秒发生”需要可核对时间锚点；平均镜头时长、切点密度等需实际计数并说明范围与方法，不从剧本页数、字幕行数或素材时长推算。对白量/留白比例也只对可核对区间测量。无法量化时用有证据的段落顺序、相对节奏描述；新稿时间预算独立标“设计估时”，不可冒充源片测量。

视频能力按[宿主工具与按需准备](media-tools.md)调用。只有用户明确要忠实逐镜还原，才读取包内[视频反推模块](../modules/video-reverse-storyboard/MODULE.md)，使用当前电脑可用工具，或为实际缺口准备必要依赖；普通叙事研究不因此变成全片逐帧任务。没有完成逐帧和完整听音，不宣称完成忠实全量反推。真实声画审阅仍需要当前宿主的模型和工具能力，安装解码器不等于模型已经看过或听过。已有反推稿可作来源，但需要实际检查它的来源、版本和覆盖。

## 从证据提取可用机制

每个重要发现都写成“具体事实/定位 → 产生的戏剧作用 → 能迁移的原则”。类型标签、紧凑/高级/烧脑等评价不能独立算分析产物。

| 维度 | 要找的可核对内容 |
|---|---|
| 类型与观看承诺 | 主类型、混合类型、基调；观众被邀请期待什么结果，开场怎样建立、后段怎样兑现或重释 |
| 人物与关系 | 谁在此刻要什么，依赖谁、对抗谁；原则/能力怎样同时带来优势和麻烦，谁持筹码，行动怎样改变关系 |
| 因果与反转 | 先前的合理预期、已有线索、触发变化的行动、新信息改变谁的下一步；区分事实揭示、目标受阻、权力易手和情绪变化 |
| 叙事节奏 | 问题何时提出、延迟和兑现；行动—反应—新选择如何交替，哪段加速、停顿、升级或回落，停顿承担什么作用 |
| 信息分配 | 观众和各角色分别知道/误以为什么，何时改变；悬念、惊讶与误会由何种信息差成立 |
| 对白艺术 | 双方目标、表面话题、隐瞒内容、说话策略、受阻后的换招、语言习惯；能听音时再分析实际语速、打断与静默 |
| 结尾与回收 | 兑现哪项承诺，哪个早期动作/物件/措辞意义改变，人物最终获得或失去什么 |

内部用轻量节奏表：`页/场/已核时码｜发生的事｜前因→行动→后果｜观众/人物信息变化｜情绪/压力变化｜下一期待｜来源ID与判断类别`。仅为必要变化建行，不强拆成固定八段、不生成100条分镜、不让安静观察型作品硬长出反派和反转。基于文本的段落长度只能比较该文本，不宣称成片快慢。

评论、热度或播放数据只能支持实际统计范围内的表现。没有留存曲线/实验不能说某个镜头或反转“导致完播”，预期吸引力属于创作判断。

## 迁移到新故事，并交给书库工具重写

默认“模仿/对标”迁移类型体验、人物互动、信息控制、节奏组织和对白策略，重新创作具体表达。用户指定只学某一维度就只学该维度；若明确改编其自有、获授权或公版素材，按所给素材与保留/改动范围建立改编基线，不误当成全新故事。公开可访问的资料本身不证明改编授权，不把借鉴包装成已获原作许可。

内部先写一张迁移卡：`采用什么机制及来源｜为什么适合本项目｜新人物欲望与关系｜新的阻力/关键选择/后果｜新对白策略｜需要重写的具体表达`。例如“公开场合通过礼貌回应逐步暴露利益冲突”是可迁移机制；原片的身份谜底、标志道具、桥段顺序和对白不随机制自动带入。

以卡片驱动实际创作，按缺口择用，不每次把全书跑一遍：

- [人物工具](coffee-break/ch04-character.md)：CB04-01能力与缺点、CB04-03有作用的细节、CB04-05行为原则，写出新人物自己的行动原因；不能只给原角色改名。
- [大纲工具](coffee-break/ch03-outline.md)：CB03-01/02的行动与因果、CB03-08的情绪推进及CB03-12/13的伏笔回收，让新职业/关系真正改变事件条件。
- [对白工具](coffee-break/ch06-dialogue.md)：CB06-01/02确定双方目标和换招，CB06-03处理潜台词，CB06-06/07发展独立声音；重新写回合，不换同义词重述名场面。
- [改写工具](coffee-break/ch07-rewrite.md)：CB07-11从地点/人物/对白寻找实质新意；CB07-05从实际稿追因、CB07-08检查揭示路径，修复搬走原作设定后出现的逻辑空缺。

长片转短片优先抽取一条有独立结果的关系矛盾或行动链，重新建立当下目标、阻力、选择与兑现；按[短片适配](shortform-craft.md)压缩重复和无关支线，保留让反转成立的铺垫与情绪反应。不要把两小时电影按百分比缩成五分钟，也不照搬原片转折间隔。多部参考只在有帮助时混用，明确各借哪一维，处理相互冲突，不把多个标志场面拼接当成原创。

从新稿检查：新人物做法是否有自身动机；换职业后规则/筹码是否真的变化；结局能否由新故事自己的前因推出；如果遮掉人名地点，是否仍在逐场复现原作的独特事件、反转次序和标志性对白。默认原创迁移若仍一一对应，应重建关键行动链与解决方式；不以“换了几项”或虚构相似度百分比证明原创。用户明确要求的忠实改编则按基线检查保真，不以该独立性检查擅改其锁定项。

## 交互、交付与接续

- **只分析**：交简明作品画像、证据支撑的节奏/人物/对白分析、可借鉴机制与实际资料范围，附直接来源和定位；不交未经要求的剧本。
- **共创探索**：已有的选择继承。仅关键方向未定时，先用上述工具生成2—3个真正不同的故事方案，让用户选人物立场/冲突/结局，不问一串空白题。
- **直接成稿**：把研究和迁移卡留在工作记录，按[标准格式](screenplay-format.md)交五项材料及请求的最多2集；回复只简述必要来源与访问限制，不把拉片表、方法编号和研究报告灌入正文。300秒/100CUT仍静默。
- **后续复用**：参考资料与分析按作品/版本保存一次，接续记录只留采用机制、锁定差异、资料定位和待核项；继续写剧集时不重复整部拉片。新版本或受影响主张变化才更新相关研究。

可并行安排资料代理核版本与公开材料、分析代理处理互不依赖的已取得区间、独立审稿代理检查实际新稿的因果与迁移。跨区间的设置—回收与知情变化由主代理合并核对；缺少代理时顺序执行。每个代理必须有实际材料和范围，不靠片名凭记忆补“观察”，不把全部草稿转给用户。
