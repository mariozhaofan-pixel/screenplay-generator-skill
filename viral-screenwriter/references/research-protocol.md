# 当期公开调研协议

参考片的类型/剧情节奏研究、公开剧本查找及模仿开发，先按[对标研究与原创迁移](reference-to-original.md)核作品版本、材料覆盖和可迁移机制；本页补充事实与出处核验。该模式不要求所学方法“当前热门”，也不把片名、梗概、字幕或拍摄稿冒充已看过的上映成片。

## 目的

调研用于校准当下语境、受众熟悉度和事实边界，不用于把热搜词贴到任何故事上。提出“实时、最近、正在流行”等新判断必须有当前来源；新采用的梗、IP设定和原话出处需要查证。已核验且本次未改变的稳定事实可沿用原来源与核验日期，不因稿中出现“经典台词”四字就在每次修改中重查。

已有剧本或分镜的高频窄改若没有新增或改变外部结论，直接沿用既有来源和核验日期，不为修改运镜、表情或一句原创对白重新联网。用户明确要求查证/更新，或本次改动引入、改变、质疑具体梗归属、现实事实、IP设定、原话出处或时效断言时，只核验受影响条目；新的发布日期只触发相关时效条目，不刷新全部研究。目标之外的旧问题不自动扩大本次编辑范围。研究是辅助事实校准，不替代 Coffee Break 主编译链；研究记录保存在后台，不塞进标准剧本正文。

## 按缺口调研

### 轻量预研

当前火种与故事推演涉及当期事实、现实专业行为或外部文化语境时，先核对影响写法成立的最小资料；纯原创、稳定关系方向没有此类缺口可直接完成内部练习，不为调研硬搜热榜。模型或子代理按[练习编排](exercise-orchestration.md)针对当前缺口选用练习并自查/逆向节拍审计；用户希望共同开发且有重大分岔时，再把经事实校准的2—3个成熟答案按[共创协议](soul-questioning.md)供选择、换一批、自定义或组合。普通细节内部完成，不把资料搜集或空白练习交回用户。按实际需要回答：

- 这个题材最近有哪些可验证的公共话题？
- 目标平台/受众正在使用哪些相关说法或形象？
- 哪些词已经过气、被误用或存在明显争议？
- 哪些 IP/新闻属于用户 brief 的必要语境？
- 场景需要哪些真实工作流程、物品用法、制度边界或圈层表达才能具体成立？

预研不应拖延写作；来源是否足以支持当前推演比数量重要。此流程属于有事实缺口的新创作，不是字段窄修的前置步骤。

### 围绕当前写法补研

围绕当前采用方向与本次写作授权，按实际缺口补齐：事实时间线、职业任务及工具、生活与制度语境、人物/品牌/IP官方设定、原话出处、受众讨论和可拍视觉符号。不强制两轮研究；候选开发可先研究，不把研究完成当用户已选择；已明确等待某项重大选择时不能借研究完成跳过，沉默不算选中。“帮我写/给一稿”可在限制内合理暂定原创细节并写稿，必需现实事实仍须有依据。已选内容继承，窄修不重开。最终只保留影响人物做法、限制、场景或镜头的资料；虚构角色行为与公开事实分开，不概括成真实群体必然如此。书籍来源未知时，不将自行设计的操作或仅凭目录猜测的步骤称为已核实书中练习。

## 查询栈

1. `主题 + 当前年份/月 + 官方/公告/发布`：确认事实和时间。
2. `主题 + 热梗/热词/话题 + 平台`：确认用法和受众。
3. `IP/人物/台词 + 官方出处`：确认角色设定和语义。
4. `主题 + 争议/评论/为什么`：寻找天然评论分歧；社区信息只作受众信号。
5. `同类短片/开源项目 + storyboard/script`：寻找结构或制作参考，不复制剧情。
6. `职业/工具/具体流程 + 官方手册/从业者访谈/操作示范`：查实影响行动的步骤和边界，不为了“职业感”添错动作。普通原创措辞和身体表现不因此自动联网。

## 台词、形象、声音与复合梗查证

### 候选与最小输入

引用台词、谐音黑话、编码化造型/姿势/道具、表情包、声音采样或平台剪辑模板，只有依赖外部文化知识才建立候选。只靠本片误会、反差或人物关系就成立的笑点直接设计，不给它硬贴网络起源。

每项取“具体主张＋目标集-场或原句＋关键台词/视觉锚点/声音线索＋用途”，已有逐镜稿可沿用CUT。已有参考帧先实际查看，模糊时只补看能区分身份的邻帧；不要求每项都有图像。纯文本原创可核对原作设定，但拟写的造型、动作和台词属于创作设计，不能作为外部身份已证实的证据。窄修不为找候选重新扫描全稿或调用视频反推全流程。

### 定向检索与停止

- 台词：校正后的独特短句加引号，必要时用合理同音/错字变体，再加人物、作品或“原版/出处”等限定。不要把模糊转写直接当原话。
- 形象：用独特标志、发型、姿势、道具等组合查询，候选身份回到原作/官方图文核对对应锚点；不凭“黑发动漫男”定名。有图像检索能力且确有必要时使用已看过的帧或主体裁切。
- 声音：只对听清的独特短句、歌词或可辨采样查源；无可靠识别则描述音色、节奏和作用，不猜曲名。
- 单次窄修先完成一轮目标查询；有冲突时补一轮有明确区分目标的消歧。一个决定性原始来源已经支持主张就停止，不为凑数量泛搜；仍不能闭合则保留待核或降为不依赖该归属的原创写法。用户明确要求追溯研究时，才按研究范围继续。

来源须写页面标题、直达链接、发布/事件日期与实际核验日期、支持的具体结论。原作/官方和完整原始发布优先；转述不等于原句，多个同源转载不算独立信号。稳定官方设定不能证明当期热度，当前传播实例也不能证明首创。故事有历史时点或正在判断某参考视频的既有引用时，须确认该语境早于目标时点；晚出的解释不能倒证当时已流行。

### 结论状态

- **已证实**：一个决定性原作/原始来源与准确台词或明确视觉/声音锚点闭合。非决定性资料需至少两类独立信号相合，但创作者是否有意引用仍不能凭此断言。
- **高概率**：锚点指向同一语境，但具体版本、出处或引用意图未闭合；只写高概率，不将推测写成官方事实。
- **未证实**：只有循环转载、无可靠匹配或普通片内笑点解释更合理；不在对白或说明中断言具体出处。
- **待核**：网络不可用、关键媒体不清、时间未知或证据冲突；保留确切缺口。

事实性改动查证未完成时，不声称已经纠正。能在授权字段内采用不依赖归属的原创写法时给出并标明；用户指定必须准确引用且没有可核出处时，交代缺口并请求原始来源，不替换成另一意思的名句。

### 让梗进入场景因果

新稿只为真正采用的外部梗建稳定 `GAG-001` 等编号，在后台研究账本中保存一条；标准剧本不显示GAG-ID或来源表：

```markdown
- GAG-001｜关联：1-2、1-4｜来源语境：…｜证据：[页面标题](直达URL)，发布/事件日…，核验日…，支持…｜状态：已证实｜本片设计：识别锚点…，改写…，兑现后的变化…
```

设计顺序是：不懂梗也可读的表层事件 → 观众先验 → 识别锚点 → 本片如何改写 → 铺垫/确认/兑现 → 人物、关系或风险发生什么变化。作品事实是查证结果，本片导演意图是创作选择，预期观众反应不是已经测得的结论。

标准剧本通过△动作、对白和必要字幕完成识别、误判与兑现，不增加分析字段。仅明确完整逐镜时，在“钩子职责与回收”中引用 GAG-ID 并写本镜独有的阶段、锚点和观众信息/OUT变化；摄影机【目的】解释形式如何作用于信息，不泛写“增加张力”，不增加逐镜父字段。跨场或跨镜不重复整段出处。

窄修只改获准集-场、原句或逐镜字段；新来源和状态简记在后台记录、获准变化的既有版本节或本次回复，保留无关研究与旧核验日，不宣称全稿研究已更新。标准剧本不新增版本/研究章节。只有用户授权同步研究说明、钩子表或关联内容时才更新那些位置，范围据此调整。

## 来源优先级

1. 平台、政府、品牌、制作方、作者、项目官方仓库/文档；
2. 可靠新闻机构、行业机构、研究论文；
3. 原始发布者、经过身份核验的访谈；
4. 社区讨论、评论区、榜单聚合，只用于“有人这样讨论”的有限结论。

无法找到一手来源时写“未找到可靠一手证据”，不得用多个转载互相循环证明。

## 研究账本

对准备使用的每项资料记录：

| 字段 | 要求 |
|---|---|
| `claim` | 准备影响剧情的具体结论 |
| `source` | 直达页面链接，不放搜索结果页 |
| `published/event date` | 发布日与事件发生日能区分则分别写 |
| `checked_at` | 当前核验日期 |
| `source tier` | 官方/可靠媒体/原始发布/社区信号 |
| `story use` | 它改变哪个角色、规则、障碍、台词或镜头 |
| `confidence` | 高/中/低 |
| `expiry` | 何时需要重查；实时榜单默认短保鲜期 |

## 热点准入门（六项全审）

1. **时效**：在目标发布时间仍可能被理解；过期则改为稳定文化参照。
2. **受众**：目标观众大概率认识；小圈层梗需要画面内自解释。
3. **因果**：移除后剧情会变弱或改变；若完全不变，就是贴纸。
4. **语义**：用法、人物关系和经典台词语境准确，不张冠李戴。
5. **权利与误导**：授权、合理引用、商标、真人身份和新闻事实边界可接受。
6. **保鲜期**：短保鲜梗不能承担整部故事唯一支点，应有脱梗仍成立的人物冲突。

任何一项明显失败，删除或降级为背景彩蛋。

冲突钩子不能建立在捏造新闻、剪掉事实前提、给真人虚构言行或故意煽动群体敌意上。争议可以保留，但必须让分歧来自故事中的真实选择、规则公平或代价排序；“愤怒诱饵”不视为合格互动机制。

## 热点/IP 的四种合格用法

- **世界规则**：热门机制改变所有人的行动条件。
- **角色资源**：角色因掌握某种流行知识获得优势，同时承担局限。
- **冲突误读**：不同群体对同一热词的理解差异制造可解释冲突。
- **伏笔回扣**：熟悉形象/台词先建立预期，后段用行动重释，但不直接复制原剧情。

只出现在标题、口播开头、屏幕贴纸或 Tag 中，默认不算合格使用。

## 经典台词与 IP 边界

- 优先使用用户明确授权、公共领域或原创化转译的素材。
- 必须直接引用时，只取剧情必要的短片段并注明出处；不复刻长段对白、连续桥段、独特角色造型或未授权衍生剧情。
- 不把网络误传句当作原作台词。查不到官方/原始出处时标“网络流传说法”，或不用。
- 真人热点不虚构其言行；新闻素材区分事实、指控、评论和创作假设。

## 研究说明的展示边界

以下是后台记录格式；只有用户明确要求研究说明，或已有逐镜稿的获准合同需要时才附在正文之外。标准剧本正文只保留故事，不默认附研究说明：

```markdown
## 当期研究与使用边界

- 调研截止：YYYY-MM-DD
- 使用：<元素>｜<来源链接>｜<进入剧情的方式>
- 排除：<元素>｜<未采用原因>
- 推断边界：...
- 权利边界：...
```

如果用户明确要求不联网，尊重要求。存在实际核验缺口时，在后台记录“研究限制：未执行当期核验”，必要时在回复简述对结果的影响；不往标准剧本里加研究章节。已有稿窄修不改无关全局账本。日期区分记录日与已知来源原核验日，不把记录日冒充新的核验结果。网络不可用时同样说明限制，继续不依赖新事实的原创部分，停止使用未经核验的“实时热门”等断言。
