# 理查德·沃尔特专项补充：人物吸引力与对白艺术

与Coffee Break的分工：继续以CB练习为主流程。以下仅当现稿出现具体问题时调用，不形成新的固定问卷。已充分覆盖的反派人性化（CB04-12）、目标与策略（CB06-01/02）、一般潜台词（CB06-03、CB08-04）、人物声音（CB06-05/06/07）、场景压缩（CB09）不另增同义卡。

## W01 观众已知信息是否产生新的戏剧交易

- **触发与输入**：角色向另一角色复述观众已经看过的事件，或者为了“怕观众看不懂”一再解释。输入该段台词、前文已公开事实、各角色当下所知及当前目标。
- **作者主张**：第2章强调尊重观众、持续保持观看兴趣；第9章反对仅让角色转述观众已知事实，但承认为强调、讽刺或衔接节奏而产生作用的重复有例外。作者谈角色听到旧事实的反应时，要求权衡其价值与复述成本。
- **Skill操作**：逐条把信息标为观众新知／角色新知／双方旧知；再写清说出它是否构成承认、威胁、掩饰、逼迫选择或改变关系。对无新作用的复述试删或从获知后的反应进入；有作用者压缩到足以完成该交易的最短说法。
- **输出与检查**：修改后的交流及一行新增后果。即使事实没变，关系或策略也应发生变化；必要理解不能被删成故弄玄虚。不把“新知分类”说成原书方法，这是本Skill的执行化。
- **来源定位**：`OEBPS/Text/Chapter_0002.xhtml`，关键词“原理6”“原理7”；`OEBPS/Text/Chapter_0009.xhtml`，小节“重复”“原理28”“台词和潜台词”。
- **增量**：CB09侧重删冗余，本项进一步区分观众与角色的信息位置，保留真正产生戏剧后果的重复。

## W02 用后续压力揭开人物，而不是首次出场全部介绍

- **触发与输入**：人物亮相很鲜明，之后却一直重复同一特质；或首场人物介绍已交代完所有心理。输入人物首次出场、后续关键场景和既定人物弧。
- **作者主张**：第8章“发展”指出，观众应随情节逐步发现人物层次；不发生本质改变的人物也可以成立，条件是性格受到挑战，观众从不同角度认识他。
- **Skill操作**：记录首次出场让观众形成的判断；寻找后文能够检验这一判断的压力事件，让人物必须作选择并承受后果。移动过早说破的解释，使其在行为中逐渐显露。人物若保持原则，展示坚持受到何种考验、暴露何种新层面；不强加洗白或成长。
- **输出与检查**：首场及相关后续场的定点修改，附“最初判断→压力下行为→新增理解”的证据链。新增层次必须与既有行为相容，不能靠突然补一个秘密推翻人物。
- **来源定位**：`OEBPS/Text/Chapter_0008.xhtml`，小节“发展”，关键词“初次相识”“巴顿”“受到过挑战”。
- **增量**：CB04-09处理打破原则显现变化，本项补足“行为原则不变但持续受到考验”的路径，并控制人物信息的揭示时机。

## W03 极端设定下的可信反应

- **触发与输入**：观众可能质疑“正常人为什么不这么做”，或角色为了情节硬犯低级错误。输入异常处境、角色确知信息、即时目标、资源限制和当前反应。
- **作者主张**：第8章的“谨慎人规则”认为，观众可接受自己不会遭遇的极端处境，但需要能够理解人物在其中的反应；可识别的人性能够建立参与感。
- **Skill操作**：先从角色已知事实出发写一种自然反应，再对照现稿。若现稿不同，找出已经建立的恐惧、关系、误判、原则或现实限制，让这个差异通过行为被看见；缺乏依据就改行动，不能临时把人物写笨来护住情节。反常选择也必须有可追踪的驱动力。
- **输出与检查**：修订的应对行动和必要前置证据。检查角色没有利用尚未知的信息，障碍不是随用随生；可信不等于所有观众一定作同一选择，也不等于消除人物缺陷。
- **来源定位**：`OEBPS/Text/Chapter_0008.xhtml`，小节“同情心”，关键词“谨慎人规则”“原理25”。
- **增量**：CB的人物目标、缺点与能力负责创造戏，本项专查已写行动能否让观众理解，防止用不可信反应强行推动情节。

## W04 反类型必须改变一次选择

- **触发与输入**：角色只凭职业、身份或群体标签就能让人预判所有行为。输入人物职责、场景目标、已写行为及刻板的默认版本。
- **作者主张**：第8章“模式化”建议先辨认熟悉的人物模式，再尝试其相反版本；观众记住的是特有品质。“描述”进一步强调通过行动与语言呈现性格，而非堆砌介绍。
- **Skill操作**：写清观众预期该角色会怎样做；试验一项与该预期相反、仍适合其经历与目标的价值选择；把它放入现有压力场景，让选择影响获得什么、失去什么或别人怎样回应。若只是改外貌、身份、口头禅而行动不变，继续改选择，或放弃该反类型提案。
- **输出与检查**：一段能展示差异的行动与对白，而非“反差人设”标签。检查新特征能持续制造故事，不是为了意外而随机拼接；用户锁定的身份与人格边界保持有效。
- **来源定位**：`OEBPS/Text/Chapter_0008.xhtml`，小节“模式化”“描述”，关键词“完全相反”“言谈举止”。
- **增量**：CB07的类型场景翻新偏向场景的新写法，本项检验人物反类型是否真正改变决策；若CB已有改写已做到这一点，直接复用，不重复执行。

## W05 把对白交锋作为一段声音组织

- **触发与输入**：每人单独说话有风格，但一放进双人场景就平、齐、像轮流朗读；或所有台词长度、力度相同。输入完整交流、双方目标与策略、情绪走向。
- **作者主张**：第9章“节奏的方法”把言语视作有词汇的音乐，关注语调、节拍、停顿及张力的制造和释放；“争论”和“大段的演讲”强调相互挑战、你来我往的交流形态。
- **Skill操作**：先保留意思，暂以短／长句、提问／拒绝／反击／躲闪、插入／截断等标出整段交锋；找出连续同拍、回应没有改变来势之处，再通过改句序、缩放句长或变换应答方式调整节奏。最终回到实际可说的台词，不把节奏标记写进正式稿。
- **输出与检查**：完整改写交流与必要的节奏诊断。检查每次转势来自人物意图，声音差异仍成立；平和、同意或沉默若承担作用应保留，不能把作者的争论主张套成全员吵架。未实际朗读只记为文本预检。
- **来源定位**：`OEBPS/Text/Chapter_0009.xhtml`，小节“节奏的方法”“争论”“大段的演讲”，关键词“有词汇的音乐”“张力”。
- **增量**：CB06-05/07偏向个人声音与习惯，本项检查两人之间整段对白的节奏关系、接力和压力变化。

## W06 去掉表演提示，再试另一种说法

- **触发与输入**：台词全靠“愤怒地、伤心地、冷笑”等提示才显得有戏，或标点、重音、省略号过多。输入该段对白、可见动作、真实意图与前后情境。
- **作者主张**：第9章认为重音和情绪通常应由语言、情境自然传出，应给演员阐释空间；相反的表面情绪有时比直白提示更有感染力。必要的新信息、明确说话对象等情况仍可附注，作者并非绝对禁用。
- **Skill操作**：先做去掉非必要提示的临时副本；检查意图与冲突是否依然读得出来，再内部尝试两种有根据的说法，如平静与激动、温柔与严厉。若反向说法增加人物层次，则用具体行动与上下文支撑；如关键信息会误读，保留最少说明。
- **输出与检查**：选定后的对白和必要提示。检查不是用含混假装潜台词，不让每句出现两个备选表演指令；试验结果属于Skill改编，不宣称作者规定了“双版本练习”。
- **来源定位**：`OEBPS/Text/Chapter_0009.xhtml`，小节“强调”“省略号”“括号中的附加说明”，关键词“不同情绪”“新的和必要的信息”。
- **增量**：CB08-03负责增加有效情绪与动作表达，本项反向查验台词是否过分依赖导演式提示；二者以实际表达效果协调，不能相互机械覆盖。
