# 项目试读与发布反馈（条件启用）

用户要求测试，或提供试读、试演、成片/发布数据时启用；普通交稿不等待观众测试。区分三种证据：模型/子代理的文本推演、实际读者或表演者的反馈、真实成片与平台指标。没有实测就明确未实测，不能把代理数、评分或“观众会喜欢”换算为爆款概率。

先锁定稿件/成片版本及实际反馈范围，再记录“集-场/可核对时点—反馈原意或指标—可能原因—最小修改—复核结果”。片段试读先让读者用自己的话说清谁想做什么、哪里不明白或想离开、还想知道什么、记住哪个具体瞬间；不先透露作者预期再让对方赞同。文本没有真实时码时用场号/原句，不能编秒点。模型检查可用同样问题，但必须标为文本诊断。

使用平台数据时保留观察时间、指标定义、分母/样本量、视频时长、流量来源及已知的封面、表演、剪辑、投放差异。未知项留空或标未知；只在可比条件下比较，单条高赞或流失位置只能提出假设，不能直接归因于某句台词。优先改变一处可检验因素，如信息释放或回应位置，其他因素尽量保持；自然发布前后的比较不是随机A/B实验。

仅修已授权的具体范围，并区分剧本缺口与表演、剪辑、包装或分发问题；不得为留存一律加反转、金句或缩短所有场景。已有迭代结果进入项目接续或研究记录，不增加正式剧本栏目；单项目观察不自动提升为[动态样本规则](daily-evolution.md)。不自行联系观众、发布、付费投放或设置监测。
