# 台词自然化

对白像念稿、像作者替人物发言，或用户说“AI味”“太书面”“不像人话”“不自然”时使用；新写的对白场成稿后也过一遍。本页是辅助执行工具，不冒充 Coffee Break 原文。[CB06](coffee-break/ch06-dialogue.md)、[对白与身体层](dialogue-performance.md)和[语言身份](character-theme.md#语言身份)决定这句话要做什么、由谁来说；本页只处理它被说出口的样子。

不改剧情、人物知情、因果和结局。用户锁定的台词、题眼、伏笔句、集尾卡点和必须听懂的设定不动；确需调整先说明位置和理由。已有稿的修改按入口“剧本窄修”执行，只改命中的句子。

## 先定情境，再写话

同一个意思，在哪说、手上在干什么、旁边有谁，说出来不一样。写对白场前内部确定：

- 声音环境：安静、嘈杂、隔着门、怕第三个人听见。
- 身体与手上的事：正在干活、赶路、刚跑完、困、疼、端着东西。
- 对谁说：上级、长辈、熟人、生人、孩子；对方此刻在不在听。
- 时间：能慢慢说，还是只够说半句。
- 此人此刻最不愿说出口的那句话。

它们决定音量、句长、能不能说完整、会不会被手上的事打断。情境没定就开写，台词容易回到“两个人面对面把话讲完整”。

## 可选手法

按人物和当场目的取用，不逐条套用，也不平均分给每个人。示例只示范方法，不作默认素材。

| 手法 | 为什么像人话 | 示例 |
|---|---|---|
| 情绪换成物件、行为或一句具体观察 | 人很少报告自己的情绪，观众自己推出来的更可信 | 不写“我很担心你”，写“你那屋的灯，我每晚都留着。” |
| 拆开一问一答：让问题悬着、答一个没人问的问题、用动作代替回答 | 不回答本身就是一种做法 | “检查结果出来了吗？”他把药盒一格一格按紧：“明天你几点的班？” |
| 信息要有此人此刻非说不可的理由：谁要什么、得不到会怎样、为什么是现在 | 互相告知早已知道的事，是说给观众听的 | 不写“你搬走都两年了”，写“门禁卡早换了，你那张刷不开。” |
| 拒绝和不同意说得慢：停一下、垫一句、给个理由 | 真实对话里答应通常快而短，拒绝才拖 | “周末来帮我搬家？”“……周末啊，我们组那个标书还没——” |
| 改口 | 先出口的那半句漏出真实想法 | “我就是路过——也不算路过，等了你一会儿。” |
| 回答前先反问一句 | 人在为难时会先拖 | “借你车用两天。”“去哪？”“……回趟老家。” |
| 借上一句里的词滑到真正想说的事 | 话题很少硬切 | “这西瓜不甜。”“你妈挑瓜才准。”“……她那件外套，你带走吧。” |
| 有动机的打断 | 抢话的人要么在控场，要么在躲 | “那天晚上我其实——”“先吃饭，菜凉了。” |
| 少叫名字 | 熟人之间只在叫住、警告、翻脸时喊全名；首次出场仍要让观众自然听到名字 | 整场不称名，最后一句：“陈立冬。” |
| 口语句法：省主语，成分补在句末，语气词跟着人走 | 书面整句没人这样说 | “挺沉的，这箱子。”“走了啊，他？” |
| 大事小说 | 情绪越重，说出来的常常越小 | 不写“你怎么能骗我”，写“你说过周五回来的。” |
| 措辞随对象和手上的事变 | 对上级更挑字眼，手上有活话就断 | 她一边给母亲梳头一边说：“别动……那笔钱，我没打算要。……低头。” |

## 排查：哪些句子是作者在说话

写完逐场扫一遍，只改命中的句子。单独一处弱信号不必动；同一场多处命中，回到上一节重写那几句，不靠换同义词。

- **先立靶再推翻**：“不是……而是……”“与其说……不如说……”。对方当场确实这么误会时才保留，否则直接说后半句。
- **制式宣言**：“宁可……也不……”“我怕的不是……是……”，三连排比，成语连用，放进哪部剧都成立的格言，每场都用金句收尾。
- **起跑和客服腔**：“说实话”“其实”“我理解你的感受”“你要相信”。
- **跟没人说过的话争辩**：“我不是说你不好”“我没有别的意思”。对方没这么说过就删。
- **替观众交代**：复述双方都知道的事；当场解释自己的动机；把主题说出口；两个人轮流陈述立场，像在辩论。
- **称呼乱换**：同一个人一会儿全名、一会儿昵称、一会儿“你这个人”，却没有关系变化作依据。
- **情绪标签动作**：提示里的“指尖微颤”“眼神一暗”“声音不大，却很有力”，只贴情绪、不改变局面。删掉，或换成会留下结果的动作。
- **预告式收尾**：“一切才刚刚开始”这类旁白或台词。
- **不受情境影响**：在吵、在跑、在忙、怕人听见，说的却是完整礼貌的长句。
- **一个腔调**：遮住名字分不出是谁，包括人人都改口、人人都“嗯……”。

## 不要改过头

- 表示被打断或说不下去的“——”“……”保留；符合人物当下状态的碎句保留，不合并成完整句，也不因此把每句都切碎。
- 不为口语化添加“嗯”“呃”“就是说”“说白了”。犹豫一处用一个停顿或一次改口就够。
- 不删比喻和反问，不为显得自然刻意调句子长短；公开的人机语料对照不支持这几条流行说法。
- 不把直说一律改成暗示。准确的直白可以留，把“我怕”换成“手心出汗”是另一种套路；必须听懂的规则、钩子和反转可以直给。
- 记忆点保留，但要从这个人、这件事的具体细节里长出来。
- 不靠粗话、方言词、网络梗或硬造的口头禅制造“真人感”；直性子的人本来就藏得少。
- 不让所有人都答非所问。回避底下要有他想要却不能说的东西，否则戏不往前走。

## 检验

1. 逐个角色重读关键对白场：只带着此人此刻知道的事、想要的东西和他的用词读他的每一句，删改他不可能知道或不会这样说的话。可交子智能体各读一人，主代理合并。
2. 按正常语速念出来，算上换气和手上的动作。默读会把拗口处抹平；念起来像致辞、像旁白、像播音的句子重写。
3. 遮住角色名，看能否分出是谁。
4. 这类问题靠自查挑不准。用户在意台词质感时，交付说明里指出一两句最值得亲口念一遍的台词及其集-场位置，不附检查清单。

## 窄修与多集

- 只获准改台词时不顺手加新动作，不改信息量；改后长度不超过原句约一成，对白时长按字数估。
- 同一句式在两集以上反复出现时，在接续文件记一行“本项目少用句式”，下一批避开。只记句式，不记具体台词。
- 导演交来的 `rewrite-authorized` 对白修订同样适用；`format-only` 不改台词，`notes-only` 可按本页指出具体句子和改法。
