# 使用当前电脑的视频能力

本Skill携带编剧方法、书库文字及轻量的[视频反推说明与脚本](../modules/video-reverse-storyboard/MODULE.md)，不打包解码器、第三方OCR/ASR运行库或模型权重。普通写作、剧本资料研究和窄修改不触发媒体安装。

## 实际遇到视频任务时

1. 先依据当前可用工具/技能清单检查已配置的能力：媒体读取、视频观看、音频听取、字幕提取、转写、OCR、时间定位。优先复用宿主原生工具和现成运行时；若有适用的视频分析技能，读取其实际说明再调用。不能因为别的电脑曾安装过，就在当前电脑假设它存在。
2. 按用户目标确认缺口。只有片名的公开资料研究用搜索与文档读取；普通参考分析按[对标流程](reference-to-original.md)处理；精确时码或逐镜任务才需要相应媒体能力。无需固定安装整套视频工具，也不把某个第三方技能设为唯一入口。
3. 用户已要求处理视频时，在当前宿主允许的权限内，可直接准备本次必需的公开依赖，不重复请求对普通环境准备的许可。安装前核对所选工具的官方文档、目标操作系统/架构及最低依赖；优先在当前项目的独立环境安装，不替换全局Python或破坏已有配置。工具包从官方发布或正常包管理器取得，不运行来源不明的安装命令。
4. 例如只有解码缺口时补FFmpeg/FFprobe；只有字幕识别缺口时选择当前环境合适的OCR；只有语音转写缺口时使用已有转写工具，或选择可在该电脑运行的本地ASR及必要权重。这些是按缺口择用的方案，不是必须安装的固定清单。不自动购买服务、创建账户或下载无关大型模型；管理员授权、宿主审批和网络限制仍按实际环境处理。
5. 安装或配置后先做有意义的小样验证：能否读指定媒体、时间戳是否可定位、转写/识别是否真的产生结果。文件下载或import成功不代表功能完成，更不代表模型已观看、听音。记录实际使用的工具、版本和未解决限制，临时脚本、依赖及输出放在当前项目，不写进只读Skill包。

自动准备是对目标电脑现有网络和权限内可安装工具的执行流程，不是保证任何网站、登录视频或专有模型都能自动取得。没有必要能力时，简明说明具体缺口，继续已能完成的文本/资料分析；不要编造已看过、精确时间、声音效果或逐帧观察。原书图片、原PDF等不随文字版携带，也不能靠装工具凭空恢复缺失素材。

## 分析标准不因工具改变

按实际声画或文本覆盖记录结论，原片事实、来源转述、推断和原创设计分开。普通叙事分析不自动升级为全片逐帧反推；用户明确要忠实完整逐镜还原时，需要实际覆盖全部相应画面与音轨。抽帧、字幕和ASR可辅助定位，不能冒充完整审阅。工具不足而只能完成局部分析时明确其范围，不能悄悄降低用户要求后宣称全量完成。
