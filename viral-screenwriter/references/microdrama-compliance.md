# 微短剧上线合规初查

用户说明作品要在抖音、红果等平台上线，或要求检查能不能上线时使用。这是编剧阶段的风险初查，不是法律意见，也不是审核结论。普通创作、练习和发布去向未定的稿件不加载本页。

## 依据

国家广播电视总局令第16号《微短剧发展管理办法》，2026年7月31日公布，2026年9月1日起施行（[原文](https://www.nrta.gov.cn/art/2026/7/31/art_113_73785.html)，2026-11-26核验）。下面只摘与剧本有关的条款；每个项目上线前按原文和平台现行规则复核，条款有变以原文为准。

- **第二十五条，禁止内容（共十一项）。** 剧本最常碰到的是：侵害未成年人合法权益或身心健康（第六项）；侮辱、诽谤他人或散布他人隐私（第七项）；宣扬拜金主义、奢靡之风，或基于种族、国籍、地域、性别、职业、身心缺陷等的歧视（第九项）；散布虚假信息，渲染暴力恐怖，教唆犯罪或传授犯罪方法（第十项）。涉及宪法与国家安全、民族、宗教、历史与英雄烈士、生态与公共健康等内容时，逐项对照原文。
- **第二十六条，语言文字。** 剧名、台词、字幕的语言文字使用有规范要求，具体查原文。
- **第二十八条，推广与正片相适配。** 推广信息要与正片内容相适配，也不得含第二十五、二十六条禁止的内容。
- **第三十四条，AI标识。** 使用人工智能技术生成、制作的微短剧，要依据有关规定在每集明显位置添加提示标识；制作机构和播出单位都有义务。交Seedance等视频模型生成的项目属于这一类：标识在后期和发布环节添加，不写进场景正文；交付剧本时在回复里提醒一句。
- **第三条、第十条，著作权。** 尊重原创、保护著作权；借鉴与改编的边界按[对标研究](reference-to-original.md)执行，改名换皮不算原创。
- **第五条，分类管理。** 按投资额度和题材分一、二、三类，备案、许可和审核流程不同；主要剧情涉及政治、军事、外交、国家安全、统战、民族、宗教、司法、公安等特殊题材的属于一类。编剧不判断投资分类，题材落入这些范围时提醒制作方。

## 剧本里先查的七处

| 风险 | 自问 | 常见改法 |
|---|---|---|
| 犯罪手法变成教学 | 作案步骤是否具体到观众能照做？ | 省去操作细节，把戏放在后果、调查和人物选择上 |
| 私刑被写成唯一的正义 | 主角的报复是否毫无代价，还被拍成痛快？ | 给主角一条可追责或合法的路，后果如实呈现 |
| 现实群体被污名化 | 坏是否被写成某个地域、性别、职业或身体状况的人天生如此？ | 把坏落到具体个人的动机和行为上 |
| 拜金与奢靡 | 炫富本身是否被当成爽点和人生终点？ | 财富服务人物处境和选择，回报落在关系和公平上 |
| 未成年人 | 是否用未成年人受害来引流，或有露骨、性化的呈现？ | 保护性表达，不直接呈现伤害过程 |
| 真实的人、企业、品牌 | 是否冒用、影射真实对象或泄露真实隐私？ | 虚构并去掉可识别特征；确需使用时先取得授权 |
| 宣发与正片不符 | 钩子、标题、预告里的桥段，正片里真的有吗？ | 宣发只用正片实际有的内容 |

## 结论怎么写

只用三档：**初查未发现明显问题**；**有待核查项**（列出集-场、对应条款和原因）；**不建议按现稿上线**（指出阻断项和最小改法）。不说“已过审”“百分之百合规”，不替主管部门、平台或法务下结论。改法按[剧本窄修](../SKILL.md#剧本窄修)的范围落进剧本，不借初查重写全剧。初查记录内部留存，用户要求时单独交付，不插进剧本正文。
