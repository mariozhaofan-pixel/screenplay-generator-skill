# 方法卡总索引：按创作问题选卡

主书为《10分钟编剧手册》（Coffee Break，简称CB），补书按缺口择一。**定位问题→读最贴近的一张执行卡→写进当前稿件**；表里每行列的是可选的卡，一张不够再读下一张，不默认通读全部卡，不同时叠加八段、15拍等结构比例。

包内只有自写方法卡：主书11章127张（[章节索引](coffee-break/index.md)），补书只有克龙B05、沃尔特B02、斯奈德B09的已读范围。卡上的书页/章节只供用户拿自己的版本核对；包里没有书的全文，也不按书补写卡上没有的内容。说法边界见[SKILL](../SKILL.md#说法边界)。

## 补书卡：只补一个具体薄弱点

先选一项够用的工具，不要求用户理解作者理论。

| 稿件问题 | 优先工具 | 已读范围 |
|---|---|---|
| 情节很多但不关心主角 | [克龙01/02](library/supplement-cron.md) | 《怎样写故事》第4、5章：专属性、欲望与私人意义 |
| 动机靠一句创伤标签解释 | [克龙03/04](library/supplement-cron.md) | 第6、7章：信念来路与过去选择；只在需要时做幕后场景 |
| 反转无因果或人物只会惊讶 | [克龙05/06](library/supplement-cron.md) | 第6、7、13章：主观理解、选择与三重为什么 |
| 开场概念普通、人设可随便替换 | [斯奈德01/02/03](library/supplement-snyder.md) | 《救猫咪》第1、3章选读：可视反差、人物匹配、切身利害 |
| 场景空转、主角被安排、解释过多 | [斯奈德04/05](library/supplement-snyder.md) | 第5、7章选读：场景变化、主动行为与口述剧情 |
| 人物登场后只重复标签 | [沃尔特02/03/04](library/supplement-walter.md) | 《剧本》第8章：揭示层次、可信反应、反类型选择 |
| 信息重复、对白像轮流朗读、全靠情绪括号 | [沃尔特01/05/06](library/supplement-walter.md) | 第2、9章：观众位置、双人声律、阐释空间 |

17项补书工具不强制人人创伤、成长、洗白或争吵；人物静态、观察型、喜剧和群像可用不同组织方式。来源之间有张力时先服从用户作品目标及实际文本：“少表演指令”与“有效动作描写”取最少必要信息，“人物变化”与“坚持原则”按本片选择，“反差”与“可信”同时检查。书中的历史市场判断、绝对化修辞和未经核实的科学说明不升级成当前平台事实。
