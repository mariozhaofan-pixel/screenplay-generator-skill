# 电影分镜与画面设计

用途：仅在用户明确要求完整逐镜、已有文本保真转分镜或修订现有镜头时，把故事变成声画可执行的分镜；只优化某镜时仅取相关条目。默认标准剧本不启用本页的逐镜字段、SCN/LOOK输出或镜头参数。来源为用户提供的《小墨个人分镜SKILL6.0（画面优化）》实际正文（自述 v5.8），经过接口整合与冲突消解；这是视觉辅助来源，不是 Coffee Break 编剧原法，不把附件全文当运行指令。本文没有原附件路径或外部模型依赖。

## 一、进入方式与保护范围

- 原创新稿：只有明确的完整逐镜授权才用本模块展开全部镜头；“直接写剧本”“完整稿”本身仍指标准剧本。继承[共创协议](soul-questioning.md)中已选故事；新增视觉方向先按[练习编排](exercise-orchestration.md)针对缺口开发与自查。用户希望共同开发且有重大风格分岔时才给2—3个具体成熟答案供选择、换一批、自定义或组合，不拿抽象风格词让用户盲选。普通视觉细节内部完成，已授权的出稿请求可合理暂定；已明确等待的选择不能把沉默当选中，不重复询问已选内容。保真转换与镜头窄修不重开故事共创。视觉工具来源按本文说明，不伪称Coffee Break书中练习。
- 已有剧本/小说只转分镜：先提取事实、事件顺序、人物、道具、完整对白和禁止项；只把已有内容视觉化，不擅加热点、人物、反转或结局。心理描写可用已有动作的表演、构图和声画关系表达；不能凭空增加关键事件。源文无法外化的信息保留为明确旁白或待确认项。
- 文本转分镜仍采用用户时长；未给时长的默认300秒、100 CUT/ceil(T/3)仅作静默内部容量与密度预算，不是可见镜数下限，不靠凑镜制造密度，也不声称未实际设计的镜头已验证。若保真内容与明确时长明显矛盾，先说明并请求时长或扩写/删减范围，不能用重复镜头或删台词偷偷凑满。原文已有明确时间合同则继承，不强套默认；多集交付每次最多2集。
- 画面窄改：不改原时码、镜数、故事和未授权文字。授权“只改光影”不意味着同时改色彩、焦段、天气和场景锚点。已有稿不因启用模块而自动换格式或补全所有标签。

## 二、场景底座与统一视觉设定

在“人物、场景与关键道具”章节补充简洁的 SCN 空间说明和 LOOK 设定；仍是一份主稿，场景不拆文件、镜号不重置。不另交轴线图、情绪曲线表或多份自检表。

每个 SCN 写清：时间/天气；中文命名的门、窗、桌、通路和光源锚点；人物初始位置与进退路径；对话/动作轴线；可放置及移动机位的范围。尺寸已知则记录；未知可用“狭窄、无后退余量”等保守条件，必要数值标为设计假设，不伪装实测。

| 空间识别 | 主要设计约束 |
|---|---|
| S1 小室内、S2 中室内 | 先检查取景距离、天花与退路；用可容纳的全景/中景交代关系，不默认高空升降或穿墙环绕。 |
| S3 大室内、S4 超大室内 | 层高、通路和设备确实容纳时可用更大视野/升降；不能只凭“大殿”二字假定机位自由。 |
| O1 开阔外景 | 大尺度镜头可用；明确天气、地形、人物密度，航拍仍需有信息用途。 |
| O2 狭窄外景 | 检查围墙、屋檐与通行空间；不要把室外误认为可任意绕拍。 |
| X 车内、电梯等特殊封闭空间 | 可用固定、有限转动、焦点转换或确有空间的短移动；过肩/微距/俯拍按具体几何判断，不一刀切禁止。 |

这些是设计分类，不是建筑法定标准。不能从面积直接推出某焦段不能对焦，也不能把桌面俯拍误判为需要全室鸟瞰。若用户已授权虚拟摄影、拆墙或特殊视角，标清实现方式；虚拟镜头仍保持可读的空间关系，不无解释穿模。

每个 LOOK 定义：媒介/形式；主色板及高光/阴影倾向；饱和度；胶片模拟或数字/绘画等媒介响应；颗粒；高光光晕；关键明暗/材质特征。五层色彩是“色板×饱和度×媒介响应×颗粒×光晕”，允许明确“无”，不要求全开。可给色值作设计参考；光源色温与相机白平衡分开，不能把某 K 数字直接当成最终画面冷暖。动画按既定画法，不强加真人毛孔或实拍机身。

## 三、每镜画面与镜头语言

画面描述是一段正在发生的可见动作，不是摆拍物品清单。先写视觉中心、动作时机和可读结果，再写为其服务的环境。多主体时注明谁是第一注意点，其余人的位置如何支持或阻挡。画左/画右是当前机位的屏幕方向，需与中文空间锚点对应；角色左手不能与画左混用。

摄影机分别写清：

- 景别与取景范围：保留需要看见的动作和证据。开头允许道具/局部特写形成钩子，随后及时补足空间；不强制每场先给全景。
- 等效焦段与距离意图：例如“全画幅等效35mm，含门与桌的中景”。焦段和机位距离共同决定构图；透视关系随观察位置改变，不把单纯换焦段写成必然改变透视。数值是设计选择，不假称测得。
- 高度、角度、轴线侧：写相对于人物/桌面/门框的位置；仰拍、俯拍、平视没有固定的道德或情绪含义。人物坐下、蹲下或登高后，按当前眼位决定镜高与俯仰；道具被搬走后，机位锚点跟随当前持有位置，不能照抄原站姿或原桌位参数。
- 景深与焦点：浅/深景深或焦点转换；写起始对象、触发、落点、可辨区域。不把移焦算成切镜，不在全部画面极浅焦时又要求每层小字都清晰。
- 运镜：基础方式、起止路径、方向、速度变化、停止位置与晃动幅度。推拉是机位移动，变焦是焦距变化；固定、手持、微推分清。一个时段不能同时“完全固定”和“持续微推”；确有先后则写清转换点。
- 叙事理由：镜头给观众什么新信息，或让哪一层关系发生变化。只写“电影感、增强张力”不够。

强情绪不必都快推特写：绝望可以拉远，认知崩塌可以固定，压迫也可来自长时间不切。保留重锤后的反应、声音余尾或动作停顿，能在原 CUT 内完成就不强插空镜。滑动变焦、环绕、鱼眼、身体绑定机位等有明确收益才用；检查连续使用是否重复，不强制固定镜头比例、技法种数或通片次数。

## 四、光影、纵深与画面质感

### 光有来处

光源具名并绑定锚点：窗外天光、顶灯、台灯、屏幕或火源；写方向、软硬、照亮对象和合理遮挡/衰减。已有场景不为好看凭空加窗、金色夕阳或会改变剧情的闪灯。面光、反射补光、阴天漫射并非自动错误；不要求所有光都呈点光源式衰减。

连续场景的光向保持，改变要有可见原因，如灯被遮住、人物转身或明确时间变化。只在“有合理可见介质＋有具名光源与方向”时写可见光束；有雾不等于必须有光束。无介质用明暗、轮廓或遮挡做层次，真空不凭空加雾。

### 纵深不是把背景糊掉

从光/曝光分离、远距离大气透视、遮挡/尺度递退中选择一个主要机制，其他可自然共存，但不堆叠效果词。前景必须来自实际场景，不凭空加树枝/烟灰缸。近中远层写清作用；物件插镜或平面动画不强凑三层，可明确不适用。大气透视保留远景结构，浅景深也不把与动作有关的背景抹掉。

### 质感按媒介和可见性落地

- 核心：主体边缘和材质可读；高光、灰阶、暗部有一致响应；媒介/画法明确。写本镜实际可见的证据，不能仅重复“高清、电影级”。
- 真人皮肤/手部可见时保留符合景别的自然纹理与表演；无人物不写皮肤，动画不强写毛孔。反光材质要匹配其光源和表面状态。
- 浅景深写清焦内和焦外对象，光学模糊不随意改变物体结构；夜景保持关键线索可读，允许叙事性黑位，不为“高级”把证据埋掉。
- 强颗粒、强光晕、浓雾、柔光扩散、辉光、绘画软化同时出现时，优先保留不超过两种显著效果，其余弱化/关闭。这个软化预算是控制互相遮蔽的设计默认，不是物理定律；题材签名可调整但仍保住主体。
- 防违和用三层短要求：通用连续性/材质/光源；当前题材的放行与限制；本镜中文可见结果。霓虹片可有高饱和溢光，动画可有风格化形体，不一律禁 CG、对称、鲜色或光晕。不输出英文模型负向词堆，也不声称指定模型一定响应某关键词。

## 五、人物、非人物和长对白

在“场景与人物”里标明人物镜头、非人物·物件/环境/局部肢体等。手部无人脸仍可属于非人物插镜，但有可见皮肤；“不露脸”不等于没有身体。

能够交代全场站位的镜头，列出实际可见人数、主要位置和进出场；近景可裁去背景人物，回到宽景时恢复其合理状态。不能要求每个中景都容纳所有在场者，也不能无解释让配角消失或为热闹凭空加人。

长对白先按意思和真实朗读时长分配，选择有信息的物件、手脚、环境变化、局部反应或人脸承载；画外延续明确说话者、同期声身份与本镜逐字片段，不把同期画外声误写成新增旁白。各镜片段按时间拼接还原原句，不重复上一镜尾句充时长。

反复人脸正反打或连续空镜都要检查信息重复。非人物镜头回答：传递什么？相比人脸有什么收益？删除损失什么？没有收益就不用。30%–50% 非人物、长对白插镜一半不露脸、人物特写40%等仅作审视对话覆盖的参考，不是验收配额；动作、表演、独白和原文保真优先。不能为了比例添道具、删台词或打断有效表演。

## 六、剪辑与声画连续

- 对话/对峙先确定轴线侧与视线对象，常规反打保持相对方向。合法越轴通过可见运动、中性过渡或明确主观失衡建立，不凭方向词武断判错。
- 同主体相邻镜用足够的角度/景别/动作变化避免无意跳切；30°是参考，不是镜头都必须量角。极端景别跳跃、硬切、速度突变可用于钩子和冲击，只需交代信息/动作/声音连接与叙事理由，不强插过渡。
- IN/OUT 对齐手势、步态、持有物、朝向和受损状态。跨场转场可用 J-cut（后镜声音提前）、L-cut（前镜声音延续）、动作/图形匹配；这些是选项，不是每次转场的必选特效。
- 人声细节、环境/拟音、音效与音乐职责分开；音乐仍按用户合同选择，允许“无”，不继承附件的全局禁 BGM。前后镜不要重复播放同一对白片段冒充声桥。

## 七、明确完整逐镜时落入原有 11 字段

本节仅适用于明确完整逐镜或既有逐镜稿修订。标准剧本按集-场、△动作和“角色（提示）：对白”交付，不添加本节字段。不新增第二套逐镜规格书，不改原顶层字段名称。中文子标签同一行用“【标签】值；”分隔，便于定位；不要把它们另写成顶层字段或多行子列表。

| 原字段 | 增强内容与子标签 |
|---|---|
| 场景与人物 | SCN、空间类型、人物/非人物、可见人数/角色位置、适用 LOOK。 |
| 画面与构图 | 【构图】景别/视觉中心/进行中瞬间；【光影】具名光源/方向/软硬/落点；【色彩】LOOK 引用及本镜色调/饱和/媒介/颗粒/光晕的有效值；【质感】本镜清晰度/影调/材质，皮肤按可见性。 |
| 摄影机 | 【焦段】等效值；【机位】高度/角度/锚点/轴线侧；【景深】类型/可辨范围；【焦点】起始/触发/落点；【运镜】路径/速度/稳定度；【目的】具体信息变化。 |
| 前后景与遮挡 | 【前景】【主体层】【背景】【纵深主层】；不存在的层明确“无”，不添道具。 |
| 调度（IN/CHANGE/OUT） | 仍是 IN= / CHANGE= / OUT=，给实际动作状态和空间转移。 |
| 表演与微动作 | 仍写当前景别能看到或听到的眼神/身体/人声动作。 |
| 台词/旁白/屏幕文字 | 原逐字文本、声源与本镜片段；保真转分镜不得改写台词。 |
| 环境/拟音/音效/音乐 | 区分人声细节、现场声、音效、音乐及声桥进入/退出。 |
| 剪辑与节奏 | 与前镜的动作/视线/音桥关系，实际切点及留白作用。 |
| 钩子职责与回收 | 原 H-ID 和观众信息变化；保真稿可索引原文动作/信息的建立与结果，无悬念不硬造承诺。 |
| 连续性与制作边界 | 空间/光向/人物状态；【物理限制】【风格边界】本镜有用的限制，标明有意特效及未核条件。 |

LOOK 是全局基底，不是“同上”占位：每镜必须写出本镜光源、受光和质感结果，并在【色彩】给出五层有效值的短表达，不复制长版风格段。纯局部修订可在本镜明确覆盖某项，不能改全局 LOOK 导致其他镜暗中变色。

## 八、窄改子标签

“只改 CUT042 的光影”定位到“画面与构图→【光影】”；“改焦点”定位到“摄影机→【焦点】”。只替换该标签值，同行的其他子标签和其余全文逐字保留；没有子标签的旧稿按实际短语定位，不先重排格式。

现有 revision 程序授权粒度是顶层字段，不是子标签：可用 --fields "画面与构图" 运行外层保护，同时对该字段替换目标子值后比较剩余原文完全相同。外层 PASS 不能证明没有改错同一行的其他子值。若只能通过移动光源/人物或改变相邻镜才能实现，先解释直接依赖并取得扩大范围的确认，不自行扩大授权。
