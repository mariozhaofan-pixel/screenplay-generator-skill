# 原创编排与文本转分镜契约：11 字段

本合同用于原创编排及已有文本的保真转分镜，采用 11 个 CUT 父字段；原片忠实逐镜还原使用反推模块自己的 9 字段合同，两者互不继承模板、研究章节或检查流程。仅明确要完整逐镜稿时加载本文件；已有稿定点修改直接读[逐镜窄修](storyboard-revision.md)，不为窄修重载本合同。

正式剧本与分镜均交付 `.md` 文件。默认产物是[标准格式剧本](screenplay-format.md)，本模板不得反向要求剧本输出 CUT 或 11 字段。关键镜头请求只展开所需局部，不执行全片格式校验。多集分镜沿用每次最多 2 集及批次文件限制。

## 可持续修改的主稿

本模式交付一份当前作品/批次的分镜主稿，包含获准范围的完整内容与稳定修改定位点。容量诊断见[静默容量诊断](shortform-craft.md#静默容量诊断)，不构成可见镜数硬下限；只有用户明确指定镜数才按该要求交付。每个实际 CUT 的字段独立成行，支持按镜号和字段修改。

同一批次沿用同一主稿路径，以版本号表示更新；当前获准范围的主稿保持完整，不为修订回传累计全剧。基线用于差异比对，可以保存在临时位置或上下文；除用户要求历史归档外，不堆放竞争版本。

已有文本保真转分镜沿用同一结构，保留原文事实、事件顺序与逐字对白；确认摘要记录“原文保真/直接转换授权”。研究节可注明未引入新现实事实，钩子表只记录原文已有信息，不为符合原创机制添加剧情。画面规则见 [电影分镜与画面设计](visual-storyboarding.md)，在原 11 字段中用同行中文子标签表达；已接受旧稿的窄改不自动补标签或重排格式。

保真稿没有不可逆代价、反转或互动诉求时，相关摘要明确“原文未设，不新增”。H-ID也可索引原文已有动作/信息的建立与结果，不必伪造戏剧悬念；首次/结果仍指向真实镜号，每镜写其具体信息职责。研究未进行时按研究协议记录本次日期及“未执行当期核验”，不伪造截止时间。

原创新稿同样允许稳定价值、安静关系、观察与循环等形式。保留下面原有摘要标签，内容写实际目标、后果、坚持或结尾体验；未设置不可逆损失、两难或争议时说明其不适用及实际承诺，不为填标签补剧情。H-ID可组织关系、信息、过程与感受的建立和结果，所有引用仍指向真实镜号。

状态接入已有摘要与CHR/SCN索引：重要内容用“明确锁定/当前采用/探索候选/尚未决定”及来源区分，修改权限独立记录；正式主稿只使用当前采用和明确锁定内容，不混入未选候选。试稿授权不等于定稿。摘要记录本次实际授权范围，不要求为了交付再确认已经决定的阶段。

## 挑战综艺摘要分支

仅已启用挑战综艺的新稿，在“方向确认摘要”添加独立可见行 `- 创作模式：挑战综艺`，用“观看焦点与目标、挑战契约、升级与最终兑现”替换模板的“主角欲望与不可逆代价、高潮选择与结局承诺”，格式见[挑战综艺模块](challenge-variety.md)。其余摘要项、11个CUT父字段及同行子标签保持不变。按需在既有“人物、场景与关键道具”章增加数字状态小表；本模式的人物目标可为群体或群像，终检检查契约兑现，不强制补个人牺牲、反转或续集钩子。其他题材与已接受稿窄修不迁移格式、不加载此模块。

## 时码与镜号

- 新稿从 `CUT001` 起连续编号，不按场景重置。一个 CUT 对应一个真实剪辑/摄影单元，不把 BEAT、动作节点或字幕条目计入 CUT 数。只有用户明确要求最低镜数时才检查可见镜数；内部密度预算不产生必交数量。
- 接受初稿后，ID 成为永久定位点，局部修改不重排编号。结构调整确需插镜时，在 `CUT042` 后使用 `CUT042A`、`CUT042B`；删镜保留缺号并在版本记录说明；全稿 ID 唯一、按数字及后缀顺序排列。既有 `S001` 稿保持其原 ID 体系，不为窄改批量改名，不混用两种前缀。
- 使用 `HH:MM:SS.mmm`；第一镜从 `00:00:00.000` 开始，最后一镜闭合到总时长。
- 相邻镜头共用切点；不重叠、不留无解释空洞。
- 一个镜头只承载一个可执行摄影机/剪辑单元。长镜头可在 CHANGE 内写多个动作节拍，但不能用一个镜号吞掉实际蒙太奇。
- 镜头长短服务信息和情绪。快不等于好；连续快切后需要可读的结果镜或呼吸镜。
- 容量诊断依[静默容量诊断](shortform-craft.md#静默容量诊断)执行；实际切镜服从信息、情绪、用户形式与保真范围，不为满足内部预算伪分镜头或压缩到台词说不完。

## 字段与校验接口

11 个父字段保持模板名称，每个父字段的完整值写在同一行，中文子标签用分号隔开；这是当前校验器读取字段值的接口。光影、色彩、质感属于“画面与构图”，焦段、机位、景深、焦点、运镜属于“摄影机”。旧稿窄修继承原字段和原短语，不补标签或迁移格式。

字段或子值窄修只执行[逐镜窄修](storyboard-revision.md)，其中包含 `revision` 调用与同行余文核对，不再执行本合同的全稿内容检查。父字段校验通过不能证明同行其他子值未改；9 字段反推稿也不能送入本模式的校验器。

新建完整 11 字段分镜，或已授权增删 CUT、改变时码/钩子表/全局剧情说明的结构修订，运行：

```powershell
python scripts/validate_output.py "分镜主稿.md" --mode final --expected-duration 实际秒数
```

`scripts/` 相对技能根目录；将“实际秒数”替换为本批真实总时长。只有用户明确要求可见最低镜数时才传 `--min-shots 数量`，内部容量预算不传给此参数。结构修订直接复核受影响因果链与时间轴，不借格式校验扩写未获准内容。

## 开头 3 秒合同

原文保真转换只分析现有机制，缺少反转或双重开头钩子不构成擅加剧情的理由。原创新稿按类型使用下列方法，不把强戏剧默认当所有形式的模板。

强戏剧/挑战开头优先同时完成两项：

- 显示非常规规则或异常结果；
- 给出可量化赌注/倒计时/人数/资源；
- 让主角做一个不可撤销动作；
- 建立观众能够复述的问题；
- 先展示高潮碎片，再回到因果起点。

安静关系、稳定价值或观察型开头可用正在发生的活动、关系位置、注意对象或感官差异建立承诺，不强加异常、倒计时和牺牲。不能只靠“你绝对想不到”“看到最后”或无因果爆炸声。第一轮承诺最迟在前20%得到实际体验或局部兑现，再以新问题、关系深化或体验变化延续观看理由。

## 持续钩子合同

- 每段有一个主要问题或体验职责，可有次问题潜伏，不要求每CUT新增悬念。
- 局部兑现后可由新规则、代价、选择、关系深化、理解变化或情绪余波继续；不能只是拖延。
- 强戏剧升级改变资源、关系、规则或时间压力；其他形式可以展示坚持、成功、铺垫与过程，不强制每场翻转价值。
- 采用反转时须至少两个前文可回看证据并影响后续行动；未设反转不强造。
- 互动可来自价值冲突、策略争议、共鸣、经验分享或细节发现，不用机械口播“你怎么看”。

## 声画合同

- 画面先能讲清动作与权力关系；旁白补充不可见信息，不逐字解释画面。
- 台词有当场用途、对象与人物口吻；允许清楚讲解、宣言、闲谈、长句和潜台词。身体层按场景设计并响应新输入，不给每句硬配动作；删无效重复，不因直白而一律改隐晦。
- 屏幕文字每次只传一个信息层，能在目标设备上读完。
- 音效用于标记规则、转折和因果，不给每镜同样的重击声。
- 音乐写能量、速度、配器和功能；无可靠来源不指定受版权保护的曲名。

## 热点与原创性

- 每个热点/IP在钩子表中标清因果作用；没有作用就删除。
- 不复刻样本的具体人物、台词、场面顺序或独特反转。
- 从样本迁移的是机制和密度，不是表面词汇。
- 如果题材本身比热点更强，允许交付“无热点依赖”版本并说明理由。

## 当前稿直接内容检查

以下用于新稿和结构修订的直接检查；日常交付不生成独立冷测任务、盲评稿或评分报告。字段窄改只执行[逐镜窄修](storyboard-revision.md)。

1. **观看承诺**：不知道 brief 的人能否理解当前类型的情境、目标/关系、主要过程与结尾？未设置牺牲或反转不因此判失败。
2. **声画分工**：可见行动、关系和结果是否可读？依赖声音的信息如实承认，不为静音复述强加字幕；无对白作品不强配解释。
3. **对白与表演**：主要人物有自身做法和口吻吗，回应是否受搭档影响，身体活动或静止是否具体，台词能否在分配时长演完？
4. **场景与衔接**：行动、预期、实际回应与后果成立吗？跨CUT可由结果、视线、并行事件、对照或声桥连接，不强求每镜都是因果转折。
5. **删梗测试**：删掉热梗后人物冲突是否仍成立？若不成立，梗是否被充分解释？
6. **回看证据测试**：反转后回看前文能否找到证据，而不是临时新增设定？
7. **生产锁测试**：地点、人数、VFX、动作和时长是否与用户资源相容？
