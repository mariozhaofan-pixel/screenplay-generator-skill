# 项目资料、人物小传与后续节奏

这是本Skill把已接入书库的方法编译成用户要求的五项交付材料，不是任何一本书原有的同名模板。默认成稿时与当前批最多2集正文一起交付，位置按[格式参考](screenplay-format.md)。用户仅要正文、局部修改或某一项资料时服从其范围，不借模板扩写。练习答案和来源记录留内部，成品呈现已经写好的内容。

## 从同一份故事状态生成

先区分已写事实、已采用设定、后续拟定发展及未决选择。新创作可在授权内构建人物与故事；整理已有稿时，不能为小传好看而暗加童年、身份、秘密、能力或未来结局。人物小传、项目梗概和后续节奏共用这一状态，成稿后逐项回填；不能各自编出不同的故事。

参考附件使用“介绍与小传—当前剧本—后续阶段”的结构。本次用户明确要求五项：项目类型、一句话介绍、项目梗概、人物小传、后续故事情节节奏。它们是作品材料，不是评分报告、书目清单或内部练习表。

## 项目类型、一句话介绍、项目梗概

- **项目类型**：用准确的形式、题材和基调帮助阅读，如“独立短片／现实题材／黑色喜剧”。形式与总集数依据当前项目；未确定的真人/动画、发行渠道、集数、预算不编成既定制作事实。类型不只是“爆款、爽、燃”等宣传词。
- **一句话介绍**：从[CB10-01](coffee-break/ch10-pitch.md)（书142／PDF161）的故事线写法中择用，以具体人物、独特处境、主动行动和核心阻力/利害构成一句可理解的话。内部比较即可，不把四种句式全部交给用户。连续项目必要时借CB10-02区分全剧与当前集，但此栏目默认介绍项目。
- **项目梗概**：按CB10-12（书155–156／PDF174–175）压缩起因，以人物目标、应对、后果与决定串成连贯叙事，包含当前已采用的结局或终点方向，不写成吊胃口的广告。独立短片概括完整故事；连续项目概括整体主线，不把首集复述冒充全剧。未成稿部分标明拟定，明确待选的重大结局保持未决；用户要求不剧透时从其要求。篇幅随规模，不机械写满一页。

## 人物小传：写能产生选择的人

先做相关书源练习，后压成“姓名＋已确定的身份/年龄范围＋一段可读小传”；重要人物详写，功能性人物只保留参与本故事的作用和做法。不要交一串只有姓名、外貌和性格标签的登记表，也不要让用户填空。

| 书源工具 | 必须实际产生的结果 | 成品中如何使用 |
|---|---|---|
| [CB04-05 行为原则](coffee-break/ch04-character.md)，书51–52／PDF70–71 | 当前必要角色在压力下惯常会做/不会做什么，以已写或拟采用的行动检验 | 写出他如何追求目标、对待他人，而非仅写“执拗、善良” |
| CB04-03 伏笔与回馈式小传，书49／PDF68 | 为与本片相关的衣着、物件、习惯、秘密或关系细节匹配具体作用；只做相关项时注明局部适配 | 只选能影响选择、关系或揭示的细节；不为凑七项发明秘密 |
| CB04-01 能力与缺点平衡，书47–48／PDF66–67 | 人物擅长的方法何时帮忙、何时造成麻烦；确有矛盾才采用 | 用同一特质的实际效用与代价写出人物层次，不随机拼反差 |
| [克龙B05-02](library/supplement-cron.md)，第5章，原EPUB锚点见卡 | 具体愿望、私人意义、阻碍它的顾虑/信念和眼下策略；动机缺口时选用 | 解释为什么这件事非他在意不可；有必要才用相关经历，不强造创伤或错误信念 |
| [沃尔特W02](library/supplement-walter.md)，第8章，原EPUB锚点见卡 | 初见判断、压力下行动和新增理解；角色持续重复标签时选用 | 区分“人物改变”和“人物逐渐显露”；不强制所有人洗白或成长 |

小传应让读者理解：他现在是谁、要什么及为何在意、惯常凭什么办法行动、谁与他互相牵制，以及哪些具体行为使他区别于其他人。发展方向已确定才写；连续项目的未来变化标为拟定，不把末期状态写成开场状态。对白习惯有戏剧作用时融入小传，可沿用[CB06-06/07](coffee-break/ch06-dialogue.md)的语言与说话原则，不额外制造人人同款口头禅。

检查时从小传挑出最重要的行为判断，在正文或已采用的后续规划中寻找其行动依据。找不到就修小传或当前获准的剧情，不能仅因小传新写了某项，就悄悄改动用户锁定正文。新创作所需的关键过去可以开发，但不能拿“父母早逝”等通用履历代替动机。

## 后续故事情节节奏：由本批后果继续发生

从本批最后一场提取人物知情、关系、资源、尚未兑现的承诺/伏笔及当前问题。后续规划从这个状态开始，不从过时的初始大纲重新起跑，也不把本批剧情改名为“后续”。

1. **生发事件。** 用[CB10-03](coffee-break/ch10-pitch.md)（书143–144／PDF162–163）从已有人物的能力/缺点、环境规则、关系或主题中选择适用入口，写出下一阶段要做的具体事情；无需四路全做。
2. **连接动作。** 用[CB03-01/02](coffee-break/ch03-outline.md)（书24–29／PDF43–48）形成“目标—行动—难题/结果”，检查上一结果为何迫使人物作下一选择。原书长片四部分/八段是源模型；此处按短片/有限集项目作适配，不强制八阶段。因果断裂时用[克龙B05-06](library/supplement-cron.md)检查剧情需要、客观条件和人物内在原因，补真实缺口。
3. **写出节奏变化。** 用CB03-08（书33–34／PDF52–53）将情绪变化系于具体事件与关系；必要时用[斯奈德SYN-04](library/supplement-snyder.md)比较前后状态，删并重复段。既有加压，也允许兑现、暂胜、停顿或余韵，不机械规定每集反转数量。
4. **安排回馈。** 沿用[CB01-08](coffee-break/ch01-story.md)（书9–10／PDF28–29）的终点承诺，并以CB03-12/13/14（书42–45／PDF61–64）的物件/事件/台词回馈核对后续需要兑现什么。新增反转若依赖前面尚未设置的线索，记为待补前提，不伪称伏笔已经埋下；保真整理不擅改前文补线索。

对外优先按附件写“第一阶段（既定/拟定集次）：具体剧情与节奏”，每阶段用连贯短段讲清核心目标、关键行动、阻力/转折、压力或情绪的变化，以及阶段结果如何引出下一步。单集粒度更合适时按集写；表格可用，但不能只有“铺垫—升级—反转—高潮”的标签。每个主要反转说明哪个前置事实改变了谁的判断/行动，不凭空换大反派或加万能能力。

范围按已定项目规模：可以用精简阶段概述后续主线直到已采用的终点，不另设“后续也只能概括2集”的限制。总集数未定时用阶段与暂定方向，不擅定90集或五季；“本次交1集”只限制交付数量，不自动等于全剧单集。已明确为独立短片或已完成最终集时，保留栏目并说明“本项目在本集完结，不设后续剧集”，简述已经兑现的收束即可，不发明续集、重述全片节奏或用生活余波硬造钩子。

后续概述不计作正文集数，但只能是开发材料；不能写成连续场头、完整动作和逐字对白、分镜或另一集正文来绕过每次最多2集。明确标注拟定范围，已采用的关系、设定和结局照常继承，不能把写进提纲当成用户已确认。

## 合并检查

- 五项与当前批正文处于同一版：类型准确，一句话有具体故事，梗概有因果，小传有行动依据，后续从实际终态继续。
- 人物知情和作者全局规划分清；小传可以透露开发信息，但角色不能因此在正文中凭空知道秘密。
- 小传中的能力/原则推动剧情，后续反转改变人物选择或代价，节奏说明由实际事件支撑。
- 只写用户请求的正文集数；项目材料保持精简可读，不让它挤掉完整场景。
- 不在交付稿里展示练习编号、书源页码、淘汰方案、评分和静默镜数；用户要求方法依据时再提供。
