# 内部全帧与音频分析协议

本协议只管理内部分析，不是最终脚本模板。全帧观察、音频听析、来源与推断记录保存在工作目录；成稿遵守 [storyboard-contract.md](storyboard-contract.md)，只写以摄影机视锥为基准的执行内容。

## 1. 锁定素材与范围

内部记录源文件绝对路径、文件大小与修改时间、视频/音轨/字幕流、指定区间和输出要求。默认全片，只有用户明确指定区间才能缩小范围。多个视频分别处理，除非用户要求合并。片头片尾、黑场、字幕卡和静帧均属分析范围，不自行跳过。

不得从文件名、旧剧本、平台文案、同目录截图推定当前视频内容；历史材料只能辅助选方法。

## 2. 全帧准备与覆盖记录

1. 读取原始帧时间戳、时间基、显示顺序和媒体流信息。变帧率按原始 PTS 定位，不用平均帧率计算冒充准确时间戳。
2. 连续解码范围内每一帧，保留源视频、连续索引和每帧原始 PTS。允许把全部帧等比缩放为 720p 或 1080p 分析代理，以减少重复的 4K 解码和读写；空间缩放不得改变帧数、顺序、时间戳、显示方向或画幅比例。不设帧间隔、不降帧率、不按 I 帧/场景变化挑图、不去重。机器变化指标可以辅助定位，但不能决定哪些帧要看。
3. 核对全帧索引、文件和原始时间戳是否一一对应；解码失败、缺帧、映射异常等记录为不完整，不能用抽样或补复制帧掩盖。
4. 按显示顺序实际查看全部帧。允许连续分批，但每批都须逐帧看清；代理图不足以判断细纹理、虚焦、颗粒或关键表情时，回看源视频相应原始帧。联系页只是承载逐帧观察，不以机器拼页代替语义审阅。导出的 PNG 保留编码方向；若源片带旋转、显示矩阵或非方形像素，查看时按 `media_probe.json` 恢复源片显示方向和显示比例，再判断屏幕左右、上下与构图，不能把未校正的编码画面当最终取景。
5. 内部记录已实际查看的连续帧区间、未完成/异常区间以及覆盖计数。重复静帧也要查看，只能合并书写结果，不能跳过查看。批次拼接无遗漏，边界需要时重复查看。
6. 机器成功读取/导出 N 帧、全帧 OCR、差分或其他模型摘要均不等于当前执行者完成 N 帧内容分析。没有实际查看不能勾选审阅完成。

播放原片有助于体会节奏，但不能替代逐帧审阅。无法在当前条件完成时如实说明阻碍，不将抽帧结果交付为全帧完整稿。

## 3. 内部事实与推断记录

关键结论内部保留 `claim / level / source / confidence / alternative`：已测量、已观察、推断、待核分别记录，必要时关联源帧/音频时段和外部查证。来源链接、证据等级和置信度不写进分镜文件。

不确定不等于可以编造：无依据的精确参数、隐藏空间或心理解释省去；对执行必需但不清的语音等就地用最小占位。整段画面未看或音频未听是流程未完成，不能用“待核”绕过完成门槛。

## 4. 镜头边界

逐一检查所有相邻帧的变化，自动切点检测仅辅助。对边界回看连续上下文，区分硬切、叠化、淡入淡出、闪白/闪黑、遮挡转场、甩镜、运动模糊和同镜内调度；不能仅凭高差分认定切镜。

相似构图正反打、低运动对话、单帧插入、黑场、慢叠化全部纳入逐帧核对。一个真实镜头一个镜号；蒙太奇逐镜拆，同镜动作写节拍，不虚构 CUT。

## 5. 摄影机视锥内的画面分析

每帧先确定取景框、视点/角度、屏幕位置和可见层次，再识别框内对象与变化。摄影机视锥是唯一空间描述基准，不画人物关系地图，不由道具或场景方位推定隐藏布局。

### 取景与构图

只记录取景框内实际可见的场景部分、人物局部、服装、道具、文字、光影和反射。写屏幕左中右/上中下、画面占比、边缘裁切、留白和视觉重心；不凭可见局部补完整人物或场景。

景别按画内裁切判断，机位以当前摄影机观察角度写。可见朝向用面向画面哪个方向或面向/背向镜头，不写角色自身左右或相对另一人物的方位。

### 纵深与遮挡

从镜头看近层、中层、远层，写可见重叠、遮挡、显露、透视缩放、反射、虚实和焦点。深度无可靠可见线索时只写二维构图，不编造实际距离。遮挡物与主体的描述限于摄影机所见的投影关系，不推定幕后位置。

出画或被完全遮挡后，只能记录不可见状态；再次显露时记录新可见状态，不能补写中间隐藏动作。

### 透视、焦点与摄影机运动

可靠元数据存在时才记精确焦距，其他情况内部结合透视/景深作类别判断；成稿优先写可见透视、景深和构图需求，不附置信度或论证。

区分机身运动、主体运动、光学变焦和数字裁切。写取景框运动方向、速度、路径、稳定度及画内投影变化；不能以主体变大就断定推轨或走近，无法区分则仅描述可见变化。晃动以画内相对稳定纹理为参照，记录水平/垂直/滚转、幅度与频率，不猜支撑设备。

### 可见动作与状态衔接

每镜记录：

- `IN`：取景框内可见对象/部位、屏幕位置、占比、镜头纵深、遮挡与焦点。
- `CHANGE`：连续帧中看见的屏幕位移、投影大小变化、朝向、遮挡/显露、入画/出画与焦点转换。
- `OUT`：切出时仍可见的状态或出画结果。

可以记录手与物体的可见接触、重叠和同步位移，但不以某人的左手/右手、桌旁/身后等对象坐标组织空间，也不能从物体移动反推看不见的拿取动作。下一镜建立新视锥，匹配的是两镜各自可见的状态，不按场景地图补足过程。

### 表演

只记录当前景别/清晰度下可见的眉眼、眼睑、视线、鼻翼、嘴角、下颌、呼吸、手部变化，并写明屏幕位置和动作节拍。面部不可见就不写微表情，脚未入画就不写脚步运动。声音中的呼吸可以进入声音字段，不能冒充可见胸口起伏。

情绪和表演意图可在内部帮助理解，但不做心理诊断、不在交付稿写推断论证；转为原片实际可见的执行动作。

### 特效与画面文字

记录效果/字幕/图形位于画幅何处、覆盖哪些可见层、遮住什么、如何出现/移动/消失。速度、定格、倒放、画幅、调色等按可见结果描述，不猜软件或插件。

## 6. 音频必须完整分析

核验所有音轨。按各轨时间戳对齐源视频范围并保留原声道，逐条完整听至少一遍；特别检查音轨起点偏移和跨镜声音。单声道低采样率副本、ASR、波形、频谱和字幕都是辅助，不能替代原音轨听析。

逐镜检查全部声音层：

- 画内对白：说话者可见且有同步发声线索；记录声音身份、逐字台词、语气、重音和停顿。
- 画外对白：可辨为当前场景的说话者但不在画或口型不可见，不能据此虚构其画外位置。
- 旁白：非现场叙事讲述；内心独白：有明确叙事/声音依据的主观思想。不能只因人物嘴没动就定为内心独白。
- 媒介声：可辨识的电话、广播、电视、录音等，无法确定设备就保留中性声源描述。
- 环境/拟音/音效：底噪、天气、人群、脚步、衣料、道具、撞击等的音色、声像、强弱、起落和混音层次；画外声不转成不可见动作。
- 音乐：配器、节奏、速度、能量、进入/退出、对白下压低或骤停；曲名无可靠识别不猜。
- 静默/抽空：实际听见哪些声音层消失、保留哪些，与可见动作或切点如何对齐。

每个声音事件定位进入、变化/峰值、退出和跨镜延续；声音边界与画面边界分别核对。无对白照样分析环境/音效/音乐。只有确认源片无音轨才可免实际听音并写“源片无音轨”，不能将提取/播放失败写成无声。

逐字台词回听校正，不依靠字幕决定说话者，不为语义顺畅补词；局部不清用 `[听不清]`。ASR/OCR 冲突回到原声与全帧文字，冲突记录留内部。OCR 如启用也处理每帧，不抽帧；OCR 完成仍不能代替画面目视审阅。

## 7. 剪辑与必要语境理解

记录真实切点、镜长、可见动作/构图匹配、声音先入/延后、声桥和速度变化。写“尾词结束时硬切至画面中央眼部特写”这类执行落点，不写“增强氛围”一类评论。

只有候选梗/IP语境会影响忠实还原时，才按 [gag-context-research.md](gag-context-research.md) 定向查证。片内观察与外部资料分开，网页不能替代本片帧或听音，更不能补写片中不存在的造型、动作、台词或画外身份。导演意图只作必要的内部理解，不要求每镜生成论证。

## 8. 完成标准

- 全部指定范围源帧已实际逐帧审阅，索引/时间戳/查看记录闭合，无抽帧、漏帧或以机器计数代替语义观察。
- 全部音轨已完整听析并逐镜对齐，或核验确认无音轨；未听完的整段不得以待核代替。
- 每镜九类执行内容齐全，切点、声画节拍和可见状态连续。
- 每条画面内容均基于当前摄影机视锥内的投影、构图和空间关系，没有角色/道具坐标或不可见世界推演。
- 不补未听清台词、不猜参数/出处；必要未知就地最小占位。
- 成品不含分析过程、来源、证据、置信度、导演意图和总结。内部材料不附入脚本。
