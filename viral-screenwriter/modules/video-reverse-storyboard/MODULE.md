# 视频反推分镜模块

将指定视频全帧逐一分析并完整听音，按真实剪辑点还原可直接执行的中文分镜脚本；所有画面描述以摄影机视锥内可见构图和空间关系为基准。用于视频拆解、反推分镜、镜头语言、调度表演和音频还原；禁止抽帧，成品不含过程、来源、证据说明或分析总结。不新增剧情或改写成视频生成提示词，除非用户另行要求。

这是由爆款编剧主入口按需读取的普通参考模块，不是独立技能入口，无需另装同名技能。脚本路径均相对本模块目录；执行命令前切换到本目录，或解析本包内脚本的实际路径。[运行环境说明](RUNTIME.md)列出Python、FFmpeg和按需依赖；缺依赖时使用目标电脑的公开通用工具，不查找开发机路径。

把当前源视频还原为可直接执行的逐镜脚本。首次反推和完整重跑必做全帧画面分析与完整音频分析；内部分析服务于脚本，不交付分析报告充当分镜。正式分镜交付 `.md` 文件，采用本模块的 9 字段原片还原合同，沿用上层每次至多 2 集及批次范围限制。

## 已有稿窄修

只改当前稿的指定镜头、字段或短语时，直接读[逐镜窄修](../../references/storyboard-revision.md)，不启动下方完整反推流程。继承原片证据、9 字段模板与稳定镜号，逐字核对授权差异，只复核实际受影响的帧/音及必要切点；不使用上层原创 11 字段校验器。未完成的原始全帧或听音审阅不能因局部修订被记为完成。

## 核心约束

以下完整审阅要求用于首次反推和完整重跑；已有稿窄修按上节限定复核范围，视锥、保真和成品边界始终有效。

- **全帧必看：** 按显示顺序逐一实际查看分析范围内的每一帧，不抽帧、不跳帧、不去重。全帧解码、导出、差分计算、联系表或正常倍速播放都不等于全帧内容审阅。
- **音频必析：** 核验全部音轨，完整听取并分析范围内每条音轨，逐镜对齐语音、环境、拟音、音效、音乐和静默。字幕或 ASR 不能代替听音，无对白不能视为无声。
- **视锥唯一基准：** 所有画面内容与空间描述从摄影机视点出发，限于取景框/视锥中实际可见的投影、层次与变化。使用屏幕左中右、上中下、画面边缘、相对镜头的近中远、可见遮挡、裁切和出入画；不以角色自身左右、道具方位或场景平面关系建立坐标，不推演画外世界。具体规则见 [references/storyboard-contract.md](references/storyboard-contract.md)。
- **成品只写执行：** 只含片名、必要执行设定和逐镜画面、摄影机、调度、表演、台词、声音、特效与剪辑。分析过程、源路径、媒体核验、方法、证据等级/置信度、来源链接、梗索引、导演意图论证、整体总结和待核清单全部留在内部，不以附录或隐藏注释塞回脚本。
- **不编造：** 只还原原片。影响执行但无法确认的内容就地保留最小占位，如 `[听不清]`、`[说话者不明]`；不写无依据的精确焦距、不可见身体动作、画外位置、心理动机、曲名或软件。

## 开始前

1. 锁定源视频、分析范围和输出位置；默认完整视频，只有用户明确指定区间才使用 `--start/--end`，不能为节省工作自行缩短范围。用户点名文件优先，不以旧结果替代。只有文件缺失或无法访问时才索取。
2. 阅读 [references/analysis-protocol.md](references/analysis-protocol.md)，执行内部全帧审阅、听音和取证要求。
3. 阅读 [references/storyboard-contract.md](references/storyboard-contract.md)，从第一镜按视锥基准与执行字段写稿。

默认创建 `<片名>_反推分镜/`，脚本为 `<片名>_反推分镜脚本.md`，内部材料放在 `_work/` 子目录。不修改源视频；首次反推不覆盖已有稿，完整重跑用版本号新目录，已有稿窄修沿用当前主稿路径。下文 `scripts/` 相对本模块目录，调用时解析为绝对路径。

## 必做流程

### 1. 准备完整画面与音轨

用 FFprobe 核验视频、全部音轨、字幕流和范围，运行：

```powershell
python scripts/prepare_video_evidence.py "<视频路径>" "<输出目录>\_work"
```

保留范围内每一帧、帧序号和原始时间戳映射，导出每条完整音轨。可用 `--analysis-height 720` 生成等比缩放的全帧代理；原视频保留供细节回看。禁止降低帧率、固定间隔抽帧、只取关键帧/代表帧、去重或跳过音频。机器产物只说明材料准备状态，不能证明已实际观看、听音或分析；候选切点也不是已确认镜头。

工具缺失时使用等价工具完成同样流程，不能降级抽样。解码缺帧、帧序/时间戳异常或音频导出失败时先解决缺口；无法解决应说明阻碍，不能将部分结果宣称为完整稿。

### 2. 全帧逐一审阅并确认镜头

按源视频显示顺序查看每一帧，黑场、重复静帧、快速闪帧、字幕卡、片尾也不跳过。可分批处理，但批次必须连续覆盖全部帧；内部记录实际查看的帧区间、未完成区间和异常。每帧须以足以辨认内容的清晰度实际查看，缩略联系表不作替代。

每帧按源片显示方向与画幅检查摄影机视锥内的可见人物/道具局部、构图、文字、表情、遮挡和变化；用连续帧追踪屏幕位移、相对镜头的纵深变化、入画/出画和切点。逐一核对全部相邻帧，区分硬切、叠化、闪白、遮挡转场、甩镜和同镜变化；自动检测只辅助定位。重复画面可合并书写，不能省去查看。

一个真实镜头一个镜号；长镜头变化写同镜节拍，快切/蒙太奇逐镜还原。画面描述始终站在摄影机位置：角色或道具是被摄对象，不是空间参照系。遮挡后/裁切外的身体、物体和动作不补全；出画后不沿用全知视角追踪。

### 3. 完整音频分析与声画对齐

无论用户是否另提音频、字幕是否齐全、有无对白或 ASR 是否可用，都必须执行音频流程。范围内每条音轨完整听取至少一遍，再回听模糊语音、音效起落和跨镜衔接；使用保留原声道的音轨判断声像和层次，16 kHz 单声道仅供 ASR 辅助。

逐镜落实画内/画外对白、旁白、内心独白、媒介声、环境、拟音、音效、音乐和静默，写明逐字内容、说话者、语气节奏、进入/峰值/退出、跨镜延续以及混音变化。声音在画外可以记录实际听感与可辨声源，但不能据此给画面补写画外人物、位置或动作。

ASR/OCR 按需使用：

```powershell
python scripts/transcribe_audio.py "<工作目录>\audio\track_00_asr_16k_mono.wav" "<工作目录>\asr_track_00"
python scripts/extract_subtitles_ocr.py "<视频路径>" "<工作目录>\ocr"
```

多音轨按各自文件分别处理。OCR 同样逐帧，不提供抽帧捷径。台词用原声、可见口型和字幕校正；不按语义补词。不能证明是内心独白时使用中性声源标签。无法确认曲名时写可听的配器、节奏、音色与起落。

只有媒体核验确认没有音轨，才写“源片无音轨”；只有实际听取确认静默，才写“静默”。无法访问或听取音轨属于未完成，不能以标记待核代替整段分析。

### 4. 必要理解与执行化

遇到会改变台词、造型、声音或剪辑还原的梗/IP引用时，按 [references/gag-context-research.md](references/gag-context-research.md) 做内部定向查证；不为普通对白和道具泛搜。来源、候选解释和导演意图不写进成品，只将原片可见/可听的造型、动作、语气、停顿、声音和切点落实到相应镜头。

逐镜 IN → CHANGE → OUT 均描述摄影机所见：起始构图状态、镜内可见变化、切出时的构图状态。用屏幕位置、相对镜头的纵深、可见重叠/遮挡、焦点和边缘裁切连接前后镜；镜头切换后按新摄影机视锥重述，不能用场景地图或人物自身左右推演。

将理解写成执行节拍，例如“尾词落下，画面右侧脸部嘴角收紧，音乐骤停，硬切眼部特写”；不写观众认知、导演心理等评论。不补未出现的剧情、台词、动机、反应镜头或转场。用户要求无时间戳时只从成稿移除时码与时长，内部定位仍保留。

### 5. 完成门槛与校验

以下要求全部满足后才交付完整稿：

- 全部源帧已按序实际查看，内部审阅范围闭合且无漏帧；机器导出成功不替代这一项。
- 所有音轨已完整听析并逐镜对齐，或已核实源片无音轨。局部听不清可占位，整段未听不能冒充完成。
- 首尾与真实切点闭合，镜内动作、可见状态、台词与声音连续。
- 每条画面描述均可回到当前摄影机视锥内的构图/空间关系，无角色坐标、场景地图推演或画外补写。
- 成品只有执行内容，无过程、来源、证据说明、导演分析和无关总结。

运行结构校验并复核内容：

```powershell
python scripts/validate_storyboard.py "<最终分镜脚本.md>"
```

校验器只检查格式，不能证明全帧审阅、听音或画面内容正确。完成后收束，不为无关出处反复分析。最终回复给脚本文件链接；只有确实未完成时简短说明实际阻碍。用户索取过程材料时另行交付，仍不混入脚本。
