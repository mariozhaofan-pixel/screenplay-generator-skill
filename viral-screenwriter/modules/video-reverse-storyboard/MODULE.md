# 视频反推分镜模块

将指定视频做全帧覆盖分析并听音，按真实剪辑点还原可直接执行的中文分镜脚本；所有画面描述以摄影机视锥内可见构图和空间关系为基准。用于视频拆解、反推分镜、镜头语言、调度表演和音频还原；不以关键帧或间隔抽样代替全帧覆盖，成品不含过程、来源、证据说明或分析总结。不新增剧情或改写成视频生成提示词，除非用户另行要求。

这是由爆款编剧主入口按需读取的普通参考模块，不是独立技能入口，无需另装同名技能。脚本路径均相对本模块目录；执行命令前切换到本目录，或解析本包内脚本的实际路径。[运行环境说明](RUNTIME.md)列出Python、FFmpeg和按需依赖；缺依赖时使用目标电脑的公开通用工具，不查找开发机路径。

把当前源视频还原为可直接执行的逐镜脚本。首次反推和完整重跑必做全帧覆盖与音频分析；内部分析服务于脚本，不交付分析报告充当分镜。正式分镜交付 `.md` 文件，采用本模块的 9 字段原片还原合同，沿用上层每次至多 2 集及批次范围限制。

## 已有稿窄修

只改当前稿的指定镜头、字段或短语时，直接读[逐镜窄修](../../references/storyboard-revision.md)，不启动下方完整反推流程。继承原片证据、9 字段模板与稳定镜号，逐字核对授权差异，只复核实际受影响的帧/音及必要切点；不使用上层原创 11 字段校验器。未完成的原始全帧或听音审阅不能因局部修订被记为完成。

## 核心约束

以下完整审阅要求用于首次反推和完整重跑；已有稿窄修按上节限定复核范围，视锥、保真和成品边界始终有效。

- **全帧覆盖（逐帧）：** 逐帧指分析范围内每一帧都进入审阅材料，不是只抽关键帧或按固定间隔抽样，也不是每帧打开一张大图。默认材料是逐帧表（每帧一行：帧号、时间戳/PTS、切点标记、变化指标）和全帧缩略图页（按显示顺序平铺每一帧的小图，格内标帧号），从头看到尾；只有难读区段才调原尺寸帧。宿主有能直接读取视频文件（read_file）的 Gemini 模型时，可由它看完整段视频与音频代替逐页看图，不必先抽帧；需要核对切点或难读处时再生成缩略图页抽查。
- **音频：** 能听音时完整听析范围内每条音轨，逐镜对齐语音、环境、拟音、音效、音乐和静默；字幕或 ASR 不能代替听音，无对白不等于无声。没有任何工具能听音时不阻塞完成，按 [分析协议第 6 节](references/analysis-protocol.md) 处理：未听过的声音层写 `[未听音]`，并在回复中说明声音未经听音验证。
- **视锥唯一基准：** 画面内容与空间关系只从摄影机视点描述，细则见 [分析协议第 5 节](references/analysis-protocol.md)，改写示例见 [references/storyboard-contract.md](references/storyboard-contract.md)。
- **成品只写执行：** 只含片名、必要执行设定和逐镜九字段执行内容；分析过程、源路径、来源、证据和总结按分镜合同的成品排除项留在内部，不以附录或隐藏注释塞回脚本。
- **不编造：** 只还原原片。影响执行但无法确认的内容就地保留最小占位，如 `[听不清]`、`[说话者不明]`；不写无依据的精确焦距、不可见身体动作、画外位置、心理动机、曲名或软件。

## 开始前

1. 锁定源视频、分析范围和输出位置；默认完整视频，只有用户明确指定区间才使用 `--start/--end`，不能为节省工作自行缩短范围。用户点名文件优先，不以旧结果替代。只有文件缺失或无法访问时才索取。
2. 阅读 [references/analysis-protocol.md](references/analysis-protocol.md)，按其执行观察、切点、视锥和听音细则。
3. 阅读 [references/storyboard-contract.md](references/storyboard-contract.md)，从第一镜按视锥基准与执行字段写稿。

默认创建 `<片名>_反推分镜/`，脚本为 `<片名>_反推分镜脚本.md`，内部材料放在 `_work/` 子目录。不修改源视频；首次反推不覆盖已有稿，完整重跑用版本号新目录，已有稿窄修沿用当前主稿路径。下文 `scripts/` 相对本模块目录，调用时解析为绝对路径。

## 必做流程

### 1. 准备逐帧表、缩略图页与音轨

```powershell
python scripts/prepare_video_evidence.py "<视频路径>" "<输出目录>\_work"
```

脚本用 FFprobe 核验视频、音轨、字幕流与范围，输出 `frame_index.csv`（逐帧表）、`sheets/`（全帧缩略图页，红色标签为机器切点候选）、每条完整音轨和内嵌字幕轨。整片逐张导出原尺寸 PNG 体积和读图成本都过高（60 秒 30fps 就是 1800 张），默认不导出；难读区段用 `--full-range 120-180`（帧号）或 `--full-range 4.0s-6.5s`（秒）追加到同一 `_work`，确需整套原尺寸帧时才加 `--export-full-frames`（可配 `--analysis-height 720`）。禁止降低帧率、固定间隔抽帧、只取关键帧/代表帧、去重或跳过音频。机器产物只说明材料齐全，不能证明已看、已听或已分析；候选切点也不是已确认镜头。

使用 Gemini 直接看片时，本脚本改为可选：只在需要核对切点或看清难读处时运行。工具缺失时使用等价工具完成同样的全帧覆盖，不能降级抽样。解码缺帧、帧序/时间戳异常或音频导出失败时先解决缺口；无法解决应说明阻碍，不能将部分结果宣称为完整稿。

### 2. 全帧通看并确认镜头

按顺序看完全部缩略图页，黑场、重复静帧、快速闪帧、字幕卡、片尾也在页上，不跳过；或由 Gemini 看完整段视频与音频；有图页时再用它抽查切点和难读区段。切点、构图、表演、光区变化和镜头/机位变化区段在图页上逐帧复核，看不清的区段用 `--full-range` 调原尺寸帧。内部记录已看的图页/帧区间、调过原尺寸帧的区段和异常；自动切点只辅助定位。一个真实镜头一个镜号；长镜头变化写同镜节拍，快切/蒙太奇逐镜还原。观察细则见 [分析协议第 2、4、5 节](references/analysis-protocol.md)。

### 3. 音频分析与声画对齐

无论字幕是否齐全、有无对白，都要核验全部音轨。能听音时每条音轨完整听取至少一遍，再回听模糊语音、音效起落和跨镜衔接；使用保留原声道的音轨判断声像和层次，16 kHz 单声道仅供 ASR。ASR/OCR 按需使用，多音轨分别处理：

```powershell
python scripts/transcribe_audio.py "<工作目录>\audio\track_00_asr_16k_mono.wav" "<工作目录>\asr_track_00"
python scripts/extract_subtitles_ocr.py "<视频路径>" "<工作目录>\ocr"
```

OCR 同样处理每一帧，内嵌字幕轨在 `subtitles/`，两者都要回到画面和声音核对。声音分层、台词校正、静默与无音轨的判定见 [分析协议第 6 节](references/analysis-protocol.md)。

### 4. 必要理解与执行化

遇到会改变台词、造型、声音或剪辑还原的梗/IP引用时，按 [references/gag-context-research.md](references/gag-context-research.md) 做内部定向查证；不为普通对白和道具泛搜。来源、候选解释和导演意图不写进成品，只将原片可见/可听的造型、动作、语气、停顿、声音和切点落实到相应镜头。逐镜 IN → CHANGE → OUT 按分析协议第 5 节记录。理解写成执行节拍，例如“尾词落下，画面右侧脸部嘴角收紧，音乐骤停，硬切眼部特写”；不写观众认知、导演心理等评论，不补未出现的剧情、台词、动机、反应镜头或转场。用户要求无时间戳时只从成稿移除时码与时长，内部定位仍保留。

### 5. 完成门槛与校验

完成程度分级记录，不能混称：

- **材料已备：** 脚本已生成逐帧表、全部缩略图页及音轨/字幕导出。只说明材料齐全。
- **全帧已审：** 全部缩略图页已按序看完（或 Gemini 已看完整段视频与音频，需要时再用图页抽查），切点和变化区段已逐帧复核，难读区段已看原尺寸帧，内部审阅记录闭合、无漏帧。
- **声音已听析 / 声音未验证：** 能听音时全部音轨已完整听析并逐镜对齐，或已核实源片无音轨；无法听音时未听过的声音层已写 `[未听音]`，并在回复中注明声音未经听音验证。

全帧已审，声音已听析或已按未验证处理，并满足下列各项，才交付完整稿：

- 首尾与真实切点闭合，镜内动作、可见状态、台词与声音连续。
- 每条画面描述均可回到当前摄影机视锥内的构图/空间关系，无角色坐标、场景地图推演或画外补写。
- 未听清的台词、未确认的参数与出处没有补写，必要未知已就地最小占位。
- 成品只有执行内容，无过程、来源、证据说明、导演分析和无关总结。

运行结构校验并复核内容；起点、终点为分析范围的秒数（整片为 0 与 `analysis_manifest.json` 中的 `probe_summary.duration_seconds`）：

```powershell
python scripts/validate_storyboard.py "<最终分镜脚本.md>" --require-timecodes --strict-coverage --expected-start <起点秒> --expected-end <终点秒>
```

用户要求无时码时省略后四个参数。校验器只检查格式，不能证明全帧审阅、听音或画面内容正确。完成后收束，不为无关出处反复分析。最终回复给脚本文件链接；只有确实未完成时简短说明实际阻碍。用户索取过程材料时另行交付，仍不混入脚本。
