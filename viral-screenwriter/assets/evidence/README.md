## 如何读取记录

`file`或`keyframe`为null、`evidence_status`为missing表示文件不可用；`original_filename`仅用于识别缺失资料。不得把原文件名拼成假路径、把公开来源链接当本地文件，或用missing条目计入新已核分母。

JSON中的`visual_review`、`support_count`等旧字段保留历史声称，同时以`review_claim_scope`和`portable_evidence`明确标注当前不可复核；它们不表示打包时重新完成审阅。历史机制内容版本仍为1，打包可用性元数据另用packaging_revision。新资料必须按[更新协议](../../references/daily-evolution.md)独立接收、实际观看/听音与登记。

普通原创写作不依赖这些缺失文件。只有用户要求重新核验上述样本、重算统计、核对该原词条或验证对应历史结论时，才需要取得对应原始资料；取得前须明确报告未完成。
